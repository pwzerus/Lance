## 疲劳规则（`horse_condition.gd`）

- 负重 = 骑手 72 + 马具 14 + 盔甲 7+3.6×档位 + 头盔 1.5+0.8×档位 + 盾 3×容量/78 + 枪 8×长度/247（kg）
- 承载 = 128×稳定性^0.9 / √速度；负重比 = 负重 / 承载
- 冲刺消耗 = 9×(0.55+0.60×负重比)×速度^1.3 每秒；恢复 17（小跑）/ 11（等待回合），负重高恢复慢
- 耐力 < 35：全速上限从 100% 平滑降到 70%（不低于小跑），加速度降到 60%
- 规则挂点（骑手原点、姿态角、手位、盾位、头位）未改
- 数值是游戏手感设定，不是实测马匹生理数据
