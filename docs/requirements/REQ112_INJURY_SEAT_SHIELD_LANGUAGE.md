## 1. 当前实现与本次要求的差距

| 项目 | 静态核对结果 | 本次需解决的问题 |
| --- | --- | --- |
| 伤害与落马 | `game/scripts/core/joust_match.gd::_apply_contact` 中，冲击超过承受阈值、平衡耗尽、生命值耗尽，任一条件均可触发 `ko`；实战生命值耗尽另判死亡。并不存在“生命值低于任意百分比后再中一击”的独立判定。 | 三种失败原因汇入类似的离鞍演出，容易被理解成按剩余血量自动弹飞。需要分离状态与动作。 |
| 晃动与坐稳 | `advance_unsteady` 已计算不稳并削弱坐稳能力，但无外力时平衡最低停在 25；`seat_lift` 仅增加有界离鞍起伏。 | 主动失衡不能越过实际支撑极限，臀部仍明显依附马背。不是单纯增加骨骼数量可以解决。 |
| 落马差异 | `visual/fallen_rider.gd::setup` 已使用双方速度、命中部位和冲击，区分失衡滑落；尚无完整的马上昏厥状态。 | 已有差异未充分传达给玩家，应在原结构上改善，不能宣称“之前完全没有分部位”。 |
| 小盾耐久 | 轻盾已有较小轮廓和更快举盾；例如英格兰轻盾耐久容量为 150、精制轻盾为 200。实际扣减取决于冲速、枪线与传力，不能只凭容量解释本次现象。 | 检查是否被过多判成擦击、真实传力是否偏低、容量与修复时机是否合理，再确定调整量。 |

仍有生命值却落马可以是有效机制：骑手可能失去坐稳能力但没有死亡。需要修正的是失衡过程、动作与说明，以及以生命值直接决定抛飞的耦合。不能为了血条清空才允许落马。

## 2. 需求范围与验收

| 编号 | 需求 | 验收要求 |
| --- | --- | --- |
| R1 | 重新校准实战的胸腹有效重击。将护甲吸收、擦击、低速接触和正面重击区分清楚。 | 同装备、冲速、命中点和枪稳条件可重现。两次有效重击后仍保持原有姿态、控制和冲锋能力的表现不合格；存活必须能由有效防护或较低冲击解释，不能一律设为“两击必死”。 |
| R2 | 分开处理伤情、意识、坐稳能力、是否离鞍及死亡。血量可以保留内部用途，但不能单独决定抛飞。 | 低生命值的擦碰不会凭血量阈值产生强烈飞出；高生命值也可被充分冲击击落。生命耗尽必须终止继续作战，但根据意识与支撑状态表现为昏厥、倒伏或死亡，不统一发射同一落马动画。 |
| R3 | 加强按部位、方向、冲速和当前姿态变化的受击与落马。既有伤情影响支撑、保护动作和恢复能力。 | 头击表现头颈滞后及上身失控；胸击表现后仰、髋部脱离；腹击表现屈身、骨盆偏移及后续翻转。方向继承实际受力和运动，不能所有部位均向后高抛。弱击与重击应明显不同。 |
| R4 | 建立骑手与马鞍的有限支撑关系，允许真实失衡后的滑脱。 | 显示坐稳、离鞍、偏移、恢复或脱离的连续过程；高速反复大幅晃动更难控制。明显越过支撑范围且未恢复时可跌落，不依赖再受一击。正常单次瞄准、换盾和前倾不得无故落马，不增加随机偏枪。 |
| R5 | 加入马上昏厥／失去战斗能力的表现。 | 可出现上身前伏、头部靠近马颈或鞍前的状态，随后根据剩余支撑停留或滑落；有接触约束，不穿过马身。昏厥后不得继续有效攻击或被正常 AI 控制。严重程度和结束比赛时机见下方建议，尚未定值。 |
| R6 | 降低小盾连续承受正面重击的能力，保留轻盾的操作价值。 | 同条件下，小盾防护范围与耐重击能力弱于可比重盾，移动较快、负担较低；重盾不能等同无敌。正面重击后的裂损、举盾受阻、骑手承压和破盾要可见，擦边与正中反馈不同。破盾后防护形状与画面同步失效，不能只扣一条隐藏耐久。 |
| R7 | 文案采用专业、克制、适合骑士题材的表达，中英文术语一致。 | 按钮说明操作；战斗提示说明实际结果；结算说明导致终局的原因。禁用含糊的“扛不住”“打趴了”等表达代替具体状态。英文按语境编写，不逐字硬译中文；不借本次技能安装宣称全游戏英文版已完成。 |

竞技场继续非致死，以得分、落马或失去比赛能力结束；实战允许致命重击。有效头盔、盾牌、护甲和角度仍须提供反制。血腥开关只改变表现。双方使用相同受创与支撑规则，前几关仍通过对手装备、反应和出枪节奏保持易上手，不能因提高伤害而突然变成新手秒杀关。

实战中未被盾牌拦截、未被有效护甲吸收的腹部正面重击，应明显提高致伤和失去战斗能力的程度，不能仅减少血条、等待第三次命中才出现动作。强冲击的后移、离鞍距离和翻转幅度应明显超过弱击；采用同条件画面对照确定幅度，保留冲击方向与惯性，不为夸张效果让所有命中同向飞出。

## 3. 建议的状态及动作方向（待确认）

| 状态变化 | 拟定表现 | 对比赛的影响 |
| --- | --- | --- |
| 坐稳 → 受创 → 回稳 | 接触点先受力，躯干和头颈依次响应，双腿与盾臂尝试重新支撑。 | 未失去作战能力时继续，恢复时间随伤情和冲击变化。 |
| 坐稳 → 失衡 → 恢复／离鞍 | 骨盆相对鞍座偏移，脚部支撑减弱；回正可恢复，越过可恢复范围则滑脱。 | 成功恢复可以继续；实际离鞍结束当前比赛。 |
| 受创 → 短暂僵直 | 握持和姿态出现短暂迟滞，但保留可恢复性。 | 不与完全昏厥混用；具体时长待测。 |
| 受创 → 昏厥 | 躯干失去主动支撑、前伏；头颈与马身接触，不固定成悬浮姿势。 | 建议完全昏厥即判失去作战能力；短演出后结算，不要求必须先落地。 |
| 致命重击 → 死亡 | 由实际冲击决定离鞍轨迹；失去支撑后四肢随身体运动。 | 仅实战，终止后不再伤害、计分或重复结算。 |

建议先在当前二维分件、骨长和关节约束上加入鞍座支撑、惯性与脱离条件，保留可控制性和资源上限。是否需要增加少量骨骼，应由具体接缝或动作自由度不足证明；不以全面改成自由刚体堆叠代替诊断。

尚未批准的具体数值：胸腹一次重击伤害、两次重击后的失能边界、小盾承击次数、短暂僵直时间、完全昏厥演出长度。开工先测当前基线，再给出初装／中装／重装和两模式的对照，不在此处凭感觉写死百分比。

游戏专属表达按项目术语覆盖通用写作建议。语言基准参考微软的[游戏本地化指南](https://learn.microsoft.com/en-us/globalization/localization/localize-games)：保持题材和语境一致，分别审查各语言。显示基准参考 [XAG 101](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/101)：检查实际文字可读性。这些参考不构成伤害数值、伤情真实性或商业质量认证。

| 中文 | 英文拟用词 | 含义 |
| --- | --- | --- |
| 失衡 | Off balance | 暂时失去稳定坐姿，仍可能恢复。 |
| 落马 | Unhorsed | 身体已失去鞍座支撑，不等同死亡。 |
| 昏厥 | Unconscious | 无法继续主动操控和攻击。 |
| 阵亡 | Killed | 仅实战的死亡结果。 |
| 盾心重击 | Solid hit to shield centre | 明确接触盾心且传力充分。 |
| 盾缘擦击 | Glancing hit to shield edge | 明确接触盾缘并发生偏转。 |
| 护甲吸收 | Armour absorbed the blow | 只有实际防护结果支持时使用。 |
| 伤重退赛 | Unable to continue | 尚未死亡但失去比赛能力，不能误报落马。 |

英文暂以英式拼写为工作提案，同一界面不可混用 centre/center、armour/armor；内部变量和存档键不改。文字、身体动作、接触音和简短图标共同传达结果，不能只依赖颜色或镜头震动。

## 5. 后续执行顺序与最低验收场景

1. 复现玩家腹部连续命中与小盾耐久：记录实际部位、遮挡、速度、护甲、伤害、冲击、平衡和盾耐久；先确认是否击中身体、盾牌或护甲。
2. 分离伤情、意识、支撑与离鞍条件；清除以生命值直接触发统一抛飞的路径，保留两模式的结束规则。
3. 完成未离鞍反应、不同部位离鞍、可恢复失衡及马上昏厥；从接触前一帧连续继承姿势和速度。
4. 调整轻重盾取舍、受损反馈及中英文说明；同条件比较，保留早期难度。
5. 进行规则、后台渲染和实际包复验。保护保持开启，不接管屏幕；正式存档不变。真人自然度与听感另行记录。

最低场景包括：轻甲腹部连续重击；重甲同条件对照；低生命值擦碰；高生命值失衡落马；左右镜像；胸／腹／头的不同受力；突然加减速与连续大幅晃动；正确回正恢复；马上昏厥；轻重盾正中／擦边／破盾；竞技场零死亡；实战有效防护可存活；同时失去比赛能力；暂停、重开和慢动作开关。逐例列出预期结果与画面，不以断言数量替代玩家体验。
