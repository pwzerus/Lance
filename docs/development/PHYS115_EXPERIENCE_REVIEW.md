# PHYS-115 动作与玩家体验复核

## PHYS-115 c2 续验交付

查看了实际 c2 的空中、五次落地、轻重甲骑乘受击与双向昏厥图。证据是后台渲染和引擎注入，没有真人试玩；原始精选截图见 `PHYS115_C2_CAPTURES`，像素及文件散列见 `PHYS115_C2_VISUAL.json`。

改善：原实际第三场头击形成的悬空单膝已在相同输入复验修复；深屈膝时有限髋部被动缓冲让脚自然接触地面。四场新包中的五次落马没有重现该姿势。躯干、四肢和盾牌保持相对运动，骑乘与离鞍连续；六组靴面检测不再穿地。

仍不能称自然度合格：双落马图中的远侧人明显缺少与背景地面的联系，虽接触数值通过，仍有悬浮观感；近侧盾、前臂和胸甲挤在一起，部分躺姿紧凑。完整重甲对局的落马收尾阶段平均约 36FPS，最长 100.603ms，也会损害冲击节奏。人工极端与真实释放合计七例收势超四秒。

下一步先在双跑道相同摄影机下对齐地面投影和阴影，而非把整个人物强行下移；用现有失败轨迹检查低速肩肘／盾尾摆，保持原验收门。再按实际落马帧追踪减少重复计算，不能降低骨架、画质、120Hz 物理或迭代精度。本轮没有重新制作声音，也没有硬件试听，打击感不能仅凭这些断言放行。

## 历史记录：c1 与此前开发（以下结论只适用于对应旧包）

证据为受保护的后台渲染、引擎注入和规则模拟，没有真人试玩或真实键鼠操作。以下不代表商业发布或玩家手感验收。

## 已观察到的改善

- 骑乘、命中和离鞍使用同一身体，位置与速度连续。重击不再只扣血和小幅后仰：冲量可经持盾手臂、上身和骨盆传递，丢失支撑后继续带着原动作落地。
- 肩部跨角度边界误判、透明头盔角支撑、整段刚性靴子以及绘制纠偏反推物理，都会把人体留在僵硬姿势。本轮逐项修正，而不是换成固定死亡动画。
- 已查看games154、mounted161、slump161与实际c1的g00/g02空中、着地画面。上身与下肢有相对弯曲，左右头盔/肩口连接保留；原悬空收起单膝的姿势没有在这些已查看样本中重现。
- 枪盾仍有有限移动时间，脚不能永久粘在马镫上。昏厥可以先伏在马颈，再失去支撑；低生命不会自动触发一段预设抛飞。

## 仍影响体验的问题

1. 二维手臂、盾和靴子能组成稳定支架，部分极端捕获姿势收势慢、躯干离地偏高。原128组中四组仍未过门，不能因为其余通过就称动作全部自然。应继续检查真实接触、摩擦和关节力矩，不以定时冻结、删掉肢体或人为把人压平来遮掩。
2. c1独立靴缘透明度复验仍有最大1.619px穿地；精确接触试验虽然消除这个小问题，却让一例昏厥滑落撑住不倒，已经否决。不能写成靴子接地全部完成。
3. 新结构的计算负担明显增加。c1专门重甲实测平均约51.5FPS，存在90ms长帧；它会削弱操作和冲击节奏，不能把旧c5约60FPS的结果沿用到这里。
4. 空中某些时刻会出现前滚、头先触地和盾臂叠在胸前。单帧可以确认连接与穿地，却不能证明整段动作自然；需要真人看完整对冲、慢动作和恢复正常速度的过渡。
5. 规则测试证明有限枪盾移动、真正支撑释放和终局一致性，并不能证明AI公平、打击有重量或声音够响。声音素材本轮未重新制作，未做硬件试听。

## 后续优先顺序

先处理仍可复现的四组极端收势，再针对 mounted_solve / fall_solve / fall_hull 的真实帧耗优化，保持骨架和画面质量；随后用实际初期装备复核正常成长，并让玩家评价受击前后是否能看懂失衡原因。不要再增加装备或新玩法来掩盖基础动作问题。

最终候选的具体复验、限制和启动入口以 PHYS115_ACCEPTANCE 与交接记录为准。

最终追加查看c1的g01落地和正常第一关命中图：原单膝悬空未重现，肢体连接存在；盾/前臂贴在胸前且头部仍抬起，画面不能据此宣称所有躺姿自然。需以连续动作与接触记录继续审查。

最终补查中文空格路径实际包双落马图：双向肢体保持连接，没有原单膝高悬；但远侧人体在透视地面上的接触感仍偏弱，胸前盾/手重叠还影响姿态辨认。列入体验问题，不把几何支撑通过等同落地观感优秀。
