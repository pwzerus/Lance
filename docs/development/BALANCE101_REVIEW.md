# BALANCE-101：固定护胸的取舍诊断与建议

2026-11-16（纽约），Codex。实际基线 `0143711c9467602954e827c5bfed9d81630b092f`，本地/远程相同；运行版本仍为 v0.4.53-c1。本轮只有诊断脚本、证据和方案，**没有改变游戏数值、AI、素材或发布包**。

## 用户问题与实际原因

用户认为护胸是最合理、最难攻破的选择，希望增加决策。不能把这个反馈直接等同于“所有姿态、所有攻击都被护胸挡住”。

1. **入门的单一攻击是有意设计**：LEVEL-100刚按用户“前几关太难”反馈让前五关主要攻胸，前三关不催马。此处护胸易用应保留。
2. **大盾同时覆盖胸腹确实存在**：这来自REQ-098明确要求的尺寸，不是隐藏圆形碰撞器扩大；实际检测沿用绘制共用多边形。简单缩小碰撞框会破坏所见即所得和既有装备差异。
3. **护胸有头部空当**：本次中立姿态样本中，36条头部目标线有34条命中头、2条先撞盾；并非护胸包住全身。后仰会把盾带上去护头，同时露出胸腹；前倾护胸仍露头。
4. **正面承压与擦边已有不同规则**：当前shield_transfer依据偏心距和实际盾角连续计算；高速稳枪正中盾会大量损失平衡，擦边会卸力。不能再把“新增破架条”当作缺失功能；应检查玩家为何读不出已有的平衡/受力。
5. 当前AI已有延迟看盾位、选择空当和最后定线。新方案应沿用这些机制，不重复加一个读即时输入的反制AI。

## 本次实际验证

`test_guard101.gd` 经 Start-MemoryBound、`--test-profile`、512MiB后台诊断保护运行，系统保留500MiB。没有渲染、没有接管屏幕、没有OS输入/真人试玩。两次运行正常退出；采样私有内存最高68.1MiB。正式档与旧包不动。

- 972次固定姿态真实扫掠：英格兰6面盾、双向真实跑道、三个盾位、前倾/中立/后仰、头/胸/腹中心±10px。用于覆盖诊断，不是胜率。
- 36次实际运动接近：轻盾0和重盾5、双向、三个盾位、三条攻击线。间隔200ms更新目标，通过正常有限速度控枪/催马和模型步进；只禁用防守方攻击，以隔离盾防护，起始近距/速度为夹具。不代表完整AI对战。
- 36次接近均有接触。护胸时4条瞄头攻击全部命中头，4条瞄胸和4条瞄腹全部先碰盾；高盾时4条瞄头全部碰盾、4条瞄腹全部命中腹。重盾护胸的两次正中胸线冲量为60.2/47.5，腹部边缘线为37.6/31.5，已存在承压差异。
- 左右自然步态和入射线不同，本次未将不同状态的冲量当作镜像等价。未覆盖其余三国全部轮廓、连续多轮胜率、真人瞄准能力、画面可读性和手感。

## 建议的调整方向（未实施，不是用户已确认的新数值）

**护胸保留为可靠的默认防守。需要改变的是遇到不同来枪时的最优选择，而不是要求每轮不停换盾。**

| 情境 | 防守选择与代价 | 进攻选择 |
| --- | --- | --- |
| 中路来枪 | 护胸保命；高速正中仍会把载荷传给骑手，持续硬接可能失衡 | 稳枪冲盾心，牺牲直接伤害换落马压力 |
| 高枪已亮出 | 提前举盾护头；胸腹随盾抬起露出 | 打头需要准确、提前定线；也可提前变低线 |
| 对方高盾/明显后仰 | 护腹或调整姿态；头部重新有风险 | 选择较大的胸腹空当，不必总追头 |
| 重盾护胸 | 维持大覆盖优势，换位比轻盾慢，负重与疲劳代价沿用 | 利用其换位时间或以正面重击累积压力 |

落地优先级：

1. 先把现有“盾挡住但人承压”表现和说明对齐：正中重击应看到盾臂压向胸、上身受力与平衡条变化，声音/短文案对应真实事件；擦边显示枪偏开与盾旋转，避免两者看起来都只是轻震。检查现有效果后局部调整，不先加一层同义数值。
2. 保留前五关简单对手；中期用提前可见的高/中/低枪变化教玩家调整。已有AI延迟/定线继续生效，不能在玩家抬盾的同一瞬间改打下方，枪盾都保持有限运动时间。
3. 比较三种进攻：持续追头、稳枪冲盾心、观察盾位打空当。若目前后两者明显不划算，再调平衡损失/对手策略，避免用无条件削弱护胸迫使所有人只瞄头。
4. 只在同装、多种输入延迟、双向和不同盾形的完整对局确认固定护胸仍普遍占优时，才调整物理覆盖；美术与判定必须同步。

不建议：站着不动举盾就额外掉耐力、必须频繁切盾的节奏惩罚、随机破防、头部必中即死、暗中缩小盾碰撞框。当前一次对冲以第一接触结算，不把“盾缘打开后马上再补一击”写成已有可用反制。

## 下一次实施的验收

- 前三关真实初始套装的慢输入代理表现不退回原3/8胜的高挫败状态；真人反馈仍独立记录。
- 针对不同可见来枪，提前选对盾位应明显降低相应风险；固定护胸无需被刻意做成最差。
- 持续瞄头不能同时拥有最高命中率、最高收益和最低操作成本；正面盾心压力、绕盾攻击各有用途。
- 盲看后台录屏/静帧能区分命中肉身、盾心硬接、盾缘滑开；实际渲染验证后才能宣称画面已改善。
- 不新增完美即时防守、额外按键或AI读心；保持现有内存保护、隔离QA、帧率与画质。

生产实现仍未调整，本轮不导出相同内容的新EXE。下一轮可以先做第一项的表现与可读性检查，再按完整对局结果决定需要改哪项平衡值。
