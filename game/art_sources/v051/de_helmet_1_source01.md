# de_helmet_1 built-in imagegen prompt

Use case: historical-scene. ONE modular helmet sprite for GALUMU pixel-art jousting game. Reference image is STYLE ONLY: hard stepped pixel edges, large grouped pixel clusters, readable broad highlights, dark outline, three-quarter facing RIGHT with face partly toward viewer. Never copy reference gold ornament/shape. Isolated complete helmet centered on square genuinely transparent canvas, no head, face, skin, eyes, shoulders, neck, mannequin, background, floor shadow, text or labels. Steel blue-grey, broad clean pixel clusters at approximately100x100 conceptual resolution then enlarged, no photo realism or noisy stippling. Historical subject: Austrian great helm around1330 inspired by KHM B74 actually observed. Broad barrel-shaped enclosed steel helm, slightly tapered/angled upper plates, flattened rounded crown, central vertical front ridge, narrow black horizontal eye slit, simple riveted plate seams, only a few breathing holes. Front ends in modest pointed lower edge under chin. No nose-protruding visor, no hinged visor, no separate late gorget, no long tail. No giant horns or plume: funeral leather crest deliberately omitted. Plain iron steel with limited dark wear, no gold.

Historical photo actually inspected separately; imagegen could not decode the museum reference file through this environment, so only the existing project style image was supplied. This is an original game adaptation, not a pixel tracing of the historical object.
