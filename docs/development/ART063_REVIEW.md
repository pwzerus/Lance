## 用户反馈与诊断

| 反馈 | 找到的原因 |
| --- | --- |
| 部分马的皮毛是密集裂纹，“很恶心” | 1）贴图本身：AI 生成的马皮把肌肉画成一层层人字形条纹（枣红、黑、栗色），栗色马的臀背还叠了 2–3 px 的细密噪点，灰马的斑纹排成一格一格的网格（`logs/art063-preview01/crop-*`）。2）采样方式：画布默认最近邻过滤，马皮也没有 mipmap，而战斗里马只按原图 0.18–0.45 倍显示（180/666 × 镜头 0.68–1.65），每个屏幕像素要跳过 2–5 个纹素，条纹就混叠成随动作闪动的裂纹（`display-*.png` 左右两列对比）。 |
| 不同部位拼接处看得到黑线 | 1）母版在肘部和膝前（腹线与腿相接处）有一段黑色外轮廓，正好落在腿部蒙皮权重的过渡区，腿一摆动就被拉进身体，成了横穿关节的黑线。2）远侧前腿网格是一个矩形区域，连带复制了胸前和腹线的像素，远侧腿前后摆动时，这些像素会从主体后面露出来，成为胸前和腹下的暗色碎片。 |
| 动作和骨架要更自然 | 腿的末段“球节→蹄底”是一整块刚体：着地承重时球节完全不下沉；只要末段转动，整只蹄子就跟着倾斜。真马承重时球节伸展下沉，蹄底仍平贴地面。 |
| GPT 生成的图案差，要 Claude 做马的美术 | 由 Claude 编写程序化重绘工具生成马皮，详见下文，没有调用任何图像生成模型。 |

## 已知边界与下一步

- 马皮是程序化“绘制”，不是逐像素手绘。与骑手的像素画相比，马皮更平滑，风格是否统一由用户判断。肌肉位置凭解剖常识在侧视图上估计。
- 远侧腿仍复制近侧腿的贴图（包括白袜），与之前一样。
- 这一轮没有做 5 分钟长测、最小化/恢复，也没有重跑 v050 解剖测试（已被 063 版取代，按设计会因骨骼段数改变而失败）以及其他 06x 测试。
- 本机加密软件会把任何写出的 `.txt` 文件加密（Godot 写的也会）。工具日志已改用 `.jsonl`；发布目录的 `SHA256SUMS.txt` 是由 Claude 的写文件工具按 Godot 打印的哈希重写的明文。
- 建议下一步：用户用 Play-Latest 试玩，先看慢步、按住加速和疾驰时的马皮观感与球节动作，然后告诉我哪匹马或哪个阶段还不对。
