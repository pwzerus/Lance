# DEV-057 独立诊断与真实接触复核

基线：`7fe878f`（v0.4.16）。负责人：Codex timing056；生产实现只读，拥有 `game/tests/test_impact_v057.gd` 与本报告。引擎、桌面、打包和 Git 由 root 运行。本报告回执为开发工程 GPU 运行，不能自动等同发布包验收。

## 为什么上一版数值通过，用户仍感觉没有冲力

用户实际试玩评价优先于上一轮自动断言。DEV-056 证明了加速输入、镜头范围、实际命中时序和图层契约，不能证明撞击有重量或落马自然。本次沿真实事件路径查到以下原因：

1. `RiderView.receive_impact` 只注入弹性速度，紧接的 `.001` time scale 把游戏时钟驱动的反应几乎冻住；音效、火花和相机先发生，人体没有先承受负载。
2. 原躯干反应只剪切中段纹理，颈、肩、手和坐骨锚点全部固定；盾牌只移动内层填充，外沿、握持臂和躯干没有一起受力。头部与胸部事件被一个 `on_shield` 布尔值折叠成相同反应。
3. 枪杆弹性两端固定、断枪片段以固定初速离开；末端接触没有沿握枪手—肩—身体连续传递。只加镜头抖动或音量无法弥补此缺口。
4. 落马基本是整身旋转，头/胸目标角仅略有差别；手臂、腿使用固定折叠，落地直接清零竖直与角速度，容易呈现僵硬木偶而非分段受力与衰减。

## 当前实现的独立静态审查

root 新共享反应将 `reaction_angle/shift`、枪压缩和盾压缩放在同一规则姿态，触发只注入速度；正常 step 分小步积分，真实目标和绘制使用同一位置。先短 loading，再 hold，让姿态先积累可见负载。sound056 使绘制握持/颈肩/腿座随此姿态，motion056 负责连续关节落马。

`step` 在本 tick 接触前推进上一击反应，`prev_*` 来自上一 tick 末，因此 sweep 包含连续反冲。两边候选先收集，再应用；`_apply_contact` 仅加反应速度，不即时移动头、盾或握枪点，第二个同 tick 候选不会因第一击瞬移而失效。`mount_velocity_y` 在推进反应之后取旧手位，避免把反冲计作马背补偿需求。此为静态审查，仍需实际运行验证。

枪与盾的主动操控速率仍由原有限速度约束决定；被动受力位移与主动目标不同，不能据此把玩家输入改成瞬移。伤害、死亡阈值和竞技场规则不应用于伪造更强的演出。

## 新测试范围与证据边界

`test_impact_v057.gd` 复用既有真实场景/投影工具。有限操控在 120 Hz 规则模拟中产生真正扫掠事件，并从事件边界转入正常 Battle `_process/_physics_process`。六个左右头/胸/盾存活案例、四个左右头/胸 1HP 致命案例、一个慢动作关闭盾牌案例。

初始高稳定性用于隔离存活受力；1HP 用于触发落马表现，均显式记录，不用于平衡或自然死亡概率结论。预接触和接触首帧是暂停推进的边界渲染；此后观察真实游戏循环。图片先保留内存，实时观察结束后写 PNG。无操作系统鼠标输入，无音质盲听，无主观“好玩”断言。

记录：首帧 loading 无位置跳变；load/hold/read/release 内头/盾/握枪位移；两方向可见枪尖与实际命中模型对齐；落马 age0、空中、释放武器、接地与衰减；正常退出恢复 time scale。区域差异和动作质量须结合图像或视频独立审查。

## 后置极端姿态故障与上肢候选修复复核

root 随后在 r2 实际包的 24 组极端 lean/guard 验证中确认 3 例朝右、低盾、头/胸落马的支撑 gap 约 15.35，无法满足原有 `<14` 规则。此为新压力范围查出的实际缺陷，前面的默认姿态通过没有覆盖它。

只读复核当前 `fallen_rider.gd:177–215` 修复：上肢地面解算除了原头侧 0.62/0.82/0.96 倍臂展目标，增加反侧 0.40/0.70、当前手横坐标和肩下方目标。新增候选加 8 分代价，优先保留原目标；仍使用同一肩肘角约束与弹簧积分，不改变骨长、主动枪盾速率或支撑 gap 阈值。腿部求解保持原候选。这样允许被长盾挡住的左臂向身体另一侧收起，而非扩大关节活动范围或让整个躯干浮高，修复与故障原因相符。

`fall-stress02.json/.log` 源工程 24 组全部通过：最大最终支撑 gap 13.772、最大收敛时间 3.533 **游戏秒**、最大骨长误差约 0.0000114、几何包络穿地量为 0。独立查看 `screenshots/v057/fall-stress02/frame_210.png`：六个代表最终姿态未见新肩肘断开、膝反折或双腿撑起躯干的桥状姿势。右上 flank 在该 3.5 秒帧仍未 settled，但 gap 已约 8.19，属于尚在收敛，不能误报成悬空。
