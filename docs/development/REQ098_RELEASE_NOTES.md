骑枪与桂冠 v0.4.51-c2

REQ-098：重击、轻重盾、命中提示与家族纹章更新。

全速稳枪正面重击更危险，擦头和慢速命中仍可存活。盾心、偏位、盾缘与盾角连续决定传力，不再只靠身体后仰判擦过。两击打正会击垮骑手的平衡。

四国各有三档轻盾和三档重盾，重量、速度、漏伤、耐久、尺寸与材质有区别。旧盾和纹章收藏保留。重盾举得慢，吸震最多15%；轻盾更快，防住的范围更小。

每面盾现在有固定的独特图案。“家族纹章”决定罩袍、马衣和枪旗，换家族纹章不再改盾面。高级枪旗可辨认不同的家族图案，已有收藏和装备选择保留。

战斗用生命、平衡、速度、马力、枪稳和盾耐久条。部位小人图显示谁挨了打，结算按轮显示命中部位和损伤。按 H 查看具体数值。实战不显示比武分数。

修复小尺寸盾纹偶发消失、营地旗误用盾纹，以及极短顿帧中枪盾和俯仰收尾跳动。极端姿势落马的肘膝接地修复沿用本阶段候选。

验证记录在项目REQ098_REVIEW与REQ098_DEBUG45文档。后台引擎验证使用隔离QA存档，不代表真人手感或硬件听感已经验收。
