## 用户反馈与诊断

用户反馈：人物骨架和动作仍然僵硬、不灵活、不丝滑。

先用 `test_rider_motion064` 渲染修改前的状态（`logs/rider064-before01`，含逐帧关节轨迹 trace.jsonl）：

- **腿是焊死的。** `seated_leg_pose` 里膝和踝都是相对髋部的固定偏移，只按马的俯仰角乘 0.3 / 0.15 转一点。轨迹显示疾驰时膝、踝与髋部的上下位移完全同步（约 6 个单位），整个骑手像一块刚体跟着马鞍晃，腿从不屈伸，也没有踩住马镫。
- **头和躯干锁死。** 后仰 45° 时头跟着一起仰，视线朝天。
- **前倾/后仰过渡本身是平滑的。** 速度弹簧有缓入缓出，但比较慢：从完全前倾到完全后仰要 1.5 秒以上（最大速度 1.6/秒，加速度 6/秒²）。这是规则层面的姿态惯性，影响躲闪时机，本轮未改，交由用户决定。

约束：骑手髋部原点、姿态角、握枪手、盾和头的位置同时是命中判定锚点（joust_match.gd），改动它们等于改规则。所以本轮只改视觉骨架，锚点逐点不变。

## 修改（game/scripts/visual/rider_view.gd）

| 位置 | 修改 |
| --- | --- |
| `seated_leg_pose` | 髋部仍随骑手运动（座位滞后、受击位移）；脚改为踩在挂于马鞍的马镫上，随马身运动，并按马身俯仰角的 60% 转动。膝盖用两段骨 IK 求解，大腿和小腿长度取自原来的实测姿态，膝盖保持在髋踝连线前方。马镫随步态轻微前后摆动（小跑和疾驰时更明显）。前倾或后仰时脚向前蹬，后仰更明显，脚跟下压。静止时每个关节与原来的固定姿势逐点一致。新增 `bar` 键（马镫皮带在马鞍上的挂点）。 |
| `_draw_seated_leg` | 马镫皮带从马鞍挂点垂下，不再跟随骑手座位。 |
| `_head_hinge` | 仅在骑乘时生效（落马的 detached 姿态带 head_rotation，不受影响）：头部反向转动前倾/后仰角的 30%，转动中心是模型的头部锚点（躯干坐标 0,-111），因此可见头盔中心仍与头部判定点重合。 |
| `_draw_pose_neck` | 只要头部铰链不是单位变换，就改用已有的可伸缩脖颈连接来画。 |

`joust_match.gd`、马匹步态、姿态惯性、枪盾限速、输入、AI 和判定一律未改。

## 边界与下一步

- 躯干仍是一整张贴图绕髋部转动，没有脊柱分段。要做脊柱弯曲，需要把躯干贴图改成蒙皮网格，工作量较大，本轮没做。
- 握枪手和盾仍是规则锚点，所以手臂只有肘部 IK 在动，没有额外的缓冲。
- 可能的下一步（需要用户决定，因为会影响手感和平衡）：加快前倾/后仰切换；给枪和盾的移动加缓入缓出（目前是匀速移动、到位即停）。
