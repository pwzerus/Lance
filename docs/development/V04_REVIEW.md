# v0.4 催马、镜头与发布审查

本轮用户追加一小时，正式开始2026-10-24 15:24:27 EDT（19:24:27 UTC），上限16:24:27 EDT（20:24:27 UTC）。继承此前攻防、像素美术和评论研究，本轮重点解决玩家澄清的“有加速，但变化很小”。

## 改动与原因

- `core/joust_match.gd:10`：点按催马由1.15改为2游戏秒，起速由230改为600游戏单位/秒²，减速由145改为85；最高疾驰仍480，接触后短冲仍515。起跑单侧距离1900改为2200，为更快起速保留接近时间。数值是游戏调校，不是马匹历史实测。
- `battle.gd:363`：缩放改为随距离的次线性变化。旧接近构图会抵消很多可见位移，造成角色主要变大、接近不明显；新镜头使屏幕间距持续缩短，同时保留近景可读性。
- 接近放缓由距离850内、0.52倍改为650内、0.72倍，减少未接触就显得慢的时间；命中顿帧与后续慢动作保留，设置仍可关闭慢动作。
- 底栏显示实际游戏速度，区分“催马”“减速中”“巡航”，避免松开后仍高速移动却显示巡航。速度条改为高对比样式；接近放缓有文字提示。
- `main.gd:115`：练习按钮与地区选择分行；压缩下拉框样式的垂直内边距，处理实际最小尺寸。窗口标题与日志明确v0.4，降低误开旧版的排查成本。
- `battle.gd:253`：AI观察间隔在原难度延迟上有±10%变化，仍按延迟观察和近身承诺执行。没有改成即时读玩家输入，也没有添加随机伤害补难度。

OS级桌面工具点按：约96ms速度280，210ms350，313ms410，427ms达到480，维持到约1.9秒；约2.96秒为396.4。按下/松开事件、boost、速度、焦点与时钟记录在 `logs/v04-desktop-click-confirmed.jsonl`，截图 `screenshots/v04/16_desktop_tap.png`。使用 `qa_desktop_profile.json`，未用正式玩家存档。

工具的拖动只持续约26ms，捕获过1个物理按住状态采样，不能称为OS级三秒长按或真人硬件测试。三秒长按结论来自引擎输入与物理步骤测试。桌面测的是AI采样修复前的候选PCK（SHA256 `BA0669389C8FAA2A570A34A4AD9029D34FFE8D83A5D4DDB4C810193DF97D30DC`）；最终AI修复不改催马、输入和镜头代码，最终EXE/PCK另做集成和自动试玩。

## 策略压力测试

144次固定种子模拟是规则检查，不是真人胜率或独立玩家评测。最终标准档：持续追头7胜5负，低枪8胜4负，看盾换目标10胜2负，全程后仰追头7胜5负；困难档固定三种打法均0胜12负，看盾换目标12胜0负。

这支持标准档不再由采样巧合让所有脚本打法全胜，也表明困难档仍能被精确的脚本换招稳定利用。后者列为长期AI多样性与平衡的限制，不为了凑目标胜率继续改数值。脚本玩家每0.5游戏秒观察，双方同默认装备；不能代替真人15–30分钟体验。记录 `logs/v04-strategy-benchmark.log` 与修复后 `v04-strategy-benchmark-jitter.log`、`game/tests/strategy_benchmark.json`。
