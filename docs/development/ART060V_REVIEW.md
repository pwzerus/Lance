# ART-060V：四套马匹运行验收（2026-11-04）

基线7e8ecf2，分支codex/v0.4，新包v0.4.20。沿用十档马匹属性、连续蒙皮和INC-059E不可见窗口停止绘制修复；没有修改马匹运动参数、玩家正式存档或旧发布包。

## 发现与修复

1. 三份新PNG的.import原先是8192字节、带`%TSD-Header`标记的内容，Godot解析失败，进而使预加载脚本不能加载。这不是美术尺寸错误。删除这三份可再生配置，由Godot重建标准文本，再设置最长边768并重导入。删除原Python写配置辅助脚本，防止重复产生不可读文件。首次失败保留在art060v-import01.log；import02/03为后续恢复记录。
2. 新图集QA脚本把普通Array赋给Array[float]，运行失败；改为原数组.fill(INF)。gallery01保留失败和超时日志，gallery02完成12张渲染。
3. 首次战斗夹具结束后存档写入受沙盒目录权限限制，退出未完成，被有限超时保护停止。改为每轮测试独立的工作目录QA存档和备份，并补齐测试装备所有权。package01已经正常退出，但退出后等待的测试协程留下ObjectDB警告；移除该等待，改为退出前验证存档，package02复查。没有为了通过测试修改游戏保存失败时留在窗口的保护行为。
