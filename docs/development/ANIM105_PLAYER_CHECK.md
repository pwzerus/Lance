# ANIM-105：后续真人体验检查表

本表是后续体验验证说明，不是本轮已经获得的玩家评价。当前工程与画面证据见ANIM105_MOTION_REVIEW；没有用自动对局的胜率替代真人体验。

使用最新外层保护启动器，保留玩家已有收藏。可先进入不计成绩的自由练习；想比较前后版本时分别使用独立QA档，不复制或覆盖正式档。

| 要看的事情 | 简单操作 | 预期体验／需要记录的异常 |
| --- | --- | --- |
| 第二关对手的手臂 | 观察对手准备、抬枪、接近和受击；左右镜像由后台已覆盖 | 枪由右手持有，盾由左手持有；透视远臂短一些但肩肘腕相连。低枪时手会降低，不应把所有低手位都当成肚子错位 |
| 枪盾的准备过程 | 上下调枪、依次护头/护胸/护腹，随后松手保持 | 腕肘配合，枪盾连续抵达；不能靠最后一帧换盾瞬间防住。记录脱节、弹到另侧、肌肉线条突然变长的位置 |
| 马背支撑与骑手恢复 | 从松手巡航到按住催马，再松手收速；穿不同重量装备 | 不稳时应是一段失衡和恢复，不能每步被绳子猛拉。轻重和疲劳仍有差别，不把所有颠簸都删掉 |
| 同一撞击之后的物件 | 分别观察完整枪脱手、断枪、持盾落马 | 枪片沿原运动飞出；盾随前臂，接地后身体逐渐停稳。不要把慢动作中的悬空时刻误判为最终躺姿 |
| 败北短特写 | 一次落马后等待结算，再重开 | 身体全程可见，镜头回到结算不闪回；不因看不到细节就把特写无限延长。记录是否过快读不清，或仍拖沓 |
| 必要信息 | 观察破盾/断枪/重伤；最小窗口下看顶部与底栏 | 读得到状态及可做的动作；无重复数字堆砌。头盔视野遮罩属于现有可选玩法，不等同HUD缺字 |

优先反馈具体时刻：版本、模式/关卡、装备、左右哪一人、抬枪或护哪个部位、正在空中还是已落地、慢动作和震动是否开启。说“这一段太僵硬”有价值，但不能据此盲目给全部骨骼增加随机摆动。

设计延展建议：先按真人反馈调整反应节奏和姿态读击，再考虑更多不同体型/个性动作。不要继续堆屏幕震动或增加独立骨骼数量来掩盖错误支撑；不要为了更夸张的特写重新延长已经缩短的败北等待。旧约94ms长帧仍按可复现场景取证，不能因为短测没重现就宣布消失。
