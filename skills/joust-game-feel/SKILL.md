# 骑枪动作与打击反馈

先读根目录 DESIGN_DECISIONS.md 的最新用户增补、当前 battle.gd、core/joust_match.gd 和相关 visual 脚本。先复现用户描述，再调参数。将主观体验与可测的故障分别记录。参考依据和适用边界见 [references/sources.md](references/sources.md)。本 Skill 不授权额外外部操作。

## 动作必须回应输入

- 分别验证按住左键、快速点按、松开、失焦和暂停。催马应改变真实位移，速度、耐力文字、步频与蹄声共同传达变化。
- 前倾约 25°、后仰约 45°，带加减速的姿态过渡。盾随架势抬升；后仰移动头部，同时暴露腰腹与平衡弱点。左右朝向均检查。
- 先保证马蹄有着地与抬腿阶段、近远腿相位关系，再增加细节。不能只平移整马或把腿当摆钟。
- 握枪手、盾手、两侧肩肘必须能辨认。让装饰保留轮廓，不能靠隐藏肢体消除穿插。

## 一次交锋的节奏

远景交代距离与双方冲锋；近身平滑靠近并有限放缓；实际接触才顿帧、局部火花、装备反冲、分层声音；交错后恢复速度并拉远。不要让每轮连续触发重复慢动作，也不要为了演出改变伤害位置。

镜头抖动施加到 Camera2D，不能移动规则世界或角色碰撞体。鼠标与触摸坐标必须经过当前 canvas 逆变换。镜头缩放、抖动和窗口拉伸后均验证可见枪尖与命中点对应。HUD 保持独立 CanvasLayer。

顿帧、恢复和镜头缓动用明确的真实时间；骑手、碎片与马腿用游戏时间。退出、暂停恢复、重开和终局全部验证时间缩放复原。近身放缓不得无限阻塞无命中交错。

## 可读的命中与反制

盾牌轮廓和真实保护范围对应；命中反馈直接显示实际受击部位。调试受击范围由 H 显式开启，默认关闭，不混入瞄准辅助。

瞄头不能无条件秒杀。头盔、盾角、架势、相对速度与平衡均有作用；腹部与躯干需要有不同的风险收益。竞技场非致死，实战允许死亡，血腥开关不改变规则。

断裂必须保留原枪的几何连续性：残柄立即缩短，断下部分从原位置飞出，带旋转、重力、地面接触和清理。效果随机源独立于比赛随机源。

## 交付验证

运行相关规则测试、实际窗口输入与摄影机测试；至少检查远景、接触近景、双向骑手、盾牌受击、飞段与暂停截图。镜头坐标和刚体运动应在实际渲染场景验证。用 physics_frame 检查刚体推进，避免单个长渲染帧内的墙钟等待假阳性。记录配置、失败和修复，导出 Windows 包后再验证该包。主观手感仍需玩家试玩反馈，不能把脚本通过称为体验已经优秀。
