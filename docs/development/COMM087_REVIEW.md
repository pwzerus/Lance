1. **普通电脑启动依赖开发环境（P0）**：旧包 Play-Safe 绝对依赖 `%USERPROFILE%/.cache/codex-runtimes/.../pwsh.exe`。新增 C# WinExe 启动器，在构建时提取并编译根目录保护器的同一 C# 核心。玩家启动不需要脚本解释器、Godot 编辑器或 Codex。游戏仍进入 1 GiB Job，900 MiB 私有内存提前停止、500 MiB 系统余量、25% CPU、单实例和退出清理保持。源保护器未改。
2. **双重损坏静默覆盖（P1）**：主档与备份均坏时，旧实现落回初始档并允许自动覆盖。`save-before/report.json`实际复现。现在先进入恢复页；可选有效手动档或新旅程，写新档前先复制并核对原文件散列，失败则不替换。退出不写损坏档。正常备份恢复也有可见提示。
3. **手动存档掩盖待保存奖励（P1）**：奖励写入失败留在内存，随后手动槽成功会清空通用 `save_error`，原界面错误地不再显示未保存。现在单独保存当前进度的 pending 状态；手动槽不清它，结算页可直接重试，重试不会重复发奖。购买/换装/外观失败回滚时也还原原来的 pending 状态。
4. **读取/覆盖缺乏确认（P1）**：手动槽已有内容时加确认；取消不修改文件。读取前先保存当前尚未落盘的奖励，再把原自动档保留为备份。不可读主档的恢复操作另行说明保留原文件。
5. **异常 JSON 无读取预算（P2）**：解析之前限制为2 MiB；写入也拒绝异常大数据。正常完整收藏远小于此值。过大主档走备份恢复，不在解析时申请任意大内存。
