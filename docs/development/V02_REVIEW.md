# v0.2 动作、镜头与攻防迭代

2026-10-24，基于用户试玩反馈的新一轮修复。前一轮三小时目标已经结束；本轮没有复用或延长旧目标。应用项目美术与代码审查 Skills，新建 joust-game-feel Skill，资料链接和限制保存在该 Skill 的 references/sources.md。未安装第三方仓库中的执行代码。

## 发现、决定和实现

| 问题 | 证据与修复 |
| --- | --- |
| 左键加速难感知、距离短 | 原始间隔1070、巡航165/冲刺310，蹄声间隔两种速度都被同一限幅值钳住。改间隔3800、巡航210/冲刺480，实际速度/耐力文字、速度相关步态与蹄声；快速点按缓存0.45游戏秒。并未发现 UI 消费能阻止全局 Input 轮询的证据。 |
| 少一条臂、看不清盾 | 远臂与一侧盾被躯干层覆盖。重排近远肩肘、两臂与盾，盾投影到胸前并扩大到80×104；实际盾判定半径38。左右方向均采集画面。 |
| 冲锋缺少节奏 | 独立 Camera2D 根据距离缩放；接近到850单位内且尚未接触时0.52倍游戏速度，近景最大1.65倍；接触40–65毫秒真实顿帧、约0.5秒恢复段，交错后拉远。背景和HUD独立CanvasLayer，震动仅作用于相机。 |
| 镜头改变后瞄准坐标风险 | 输入点经过当前 canvas 的逆变换回到世界，实际窗口验证放大后能瞄向可见头部。相机缓动期间固定屏幕点对应的世界点会自然变化，测试先固定摄影机再断言。 |
| 断枪前段直接消失 | 断裂事件记录原手点、方向与长度；前段连续拆成两根刚体，带旋转、重力、地面接触与四秒清理；不参与伤害。残柄长度与规则同步。 |
| 头部固定秒杀、盾无反制 | 移除实战固定110伤害分支；头盔/护甲、区域倍率、冲击和平衡决定结果。前倾抬盾，后仰移动头但暴露腰腹并降低平衡。AI按难度反应间隔观察后再改变防守，不每帧读输入反制。 |
| 姿态过快、后仰不足 | 姿态使用加速受限的角度速度，前倾25°/后仰45°。马腿采用着地/抬腿阶段及两段腿的几何解算，步频随实际速度变化。 |
| 命中读不清、反馈不足 | 武器尖高光、接触局部闪花、受击回摆、盾闪光、断裂与冲击声叠加、双方命中部位文字；H可查看真实受击区，默认关闭。战斗停营地旋律，增加随速度变化的低音量风声。 |

## 验证边界

规则测试包含114项断言（包括装备目录），场景测试40项，新专项测试增加长距离接触时间、真实速度、姿态角、头部非必杀、盾格挡、腰腹击落、实际镜头坐标、点击缓存、碎片运动/暂停/清理和拉远。完整结果以 logs/v02-* 和测试报告为准，不把断言数量当作对战场数。

专项测试最初出现两个失败：摄影机仍在缓动导致固定屏幕点漂移；单次墙钟等待在长渲染帧内不足以观察刚体同步。分别固定测试摄影机、改为跨16个 physics_frame 验证位移后通过。首次 headless 集成输入因视口拉伸和原固定屏幕点不再适应远镜头而失败；改用投影到视口的目标坐标并执行实际窗口测试，未降低玩法要求。

后续增加同一固定枪路的三项检查：站直命中头部、前倾由盾先拦截、后仰完全避开；专项检查合计26项。AI姿态会改变目标位置，镜头瞄准 fixture 中固定双方姿态后再发送真实视口鼠标事件，实际角度与预期一致。教学圈另设顶层绘制节点，避免被盾和人物贴图覆盖。

首次并发执行导出程序验收时出现内存分配及WebP解码错误；独立重试40项检查通过。逐项核对PCK目录的46份有效负载MD5全部匹配，未发现包内损坏。原因未确定，不把一次失败掩盖为成功。之后独立运行完整自动试玩在约75秒内完成两模式与9张截图，冲锋期间多数采样为60 FPS，未构成跨设备性能基准。早期源码自动试玩曾人为停止，不能算完整通过；以发布包完成记录为证。

历史性与可玩性参数分开。当前没有连续枪杆弯曲材料仿真、精细局部穿甲、完整伤残系统或逐帧手绘马步。放大可能暴露分件接缝；H区域图是可选教学显示，不能保证所有像素外轮廓均为碰撞体。合成音效已接入，专业混音与真人主观手感仍待试玩。保存正式玩家数据，QA测试使用独立文件；旧v0.1发布包保留。
