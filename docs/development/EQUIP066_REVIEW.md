## 1. 用户需求与评估

| 需求 | 评估 | 本轮做法 |
| --- | --- | --- |
| 盔甲、纹章、盾牌纹章要看得清 | 合理，属于基本可读性。诊断出两处真问题：① 对战时盾面底色取自盾牌所属地区，纹章只是固定颜色的线条，导致"赤地银山形"画在蓝盾上，纹章名称与画面不符；② 纹章卡片只画空白色盾，看不到图案 | 纹章决定盾面（底色与图案，按盾形裁切并描边），盾牌品质只决定做工（木边→生皮包边→铁边铁心→铆钉→黄铜→镀金）。纹章卡片画出真实纹章，盾牌卡片显示玩家自己的纹章 |
| 加入马衣：纯装饰、不提供防护、只加一点重量 | 合理且符合历史，马衣本来就用来展示纹章。风险：只加重量、毫无收益的装饰，在意输赢的玩家会一律不穿（"Fashion Souls"现象，见资料 C3） | 新增"马衣"槽：不披、亚麻半马衣 2.5 kg、羊毛纹章马衣 5 kg、丝绒金缘马衣 6.5 kg。马衣与马体同一套蒙皮网格、随动作变形，并显示骑手纹章。重量注明为游戏估计（没有原物数据） |
| 按真实装备设定重量 | 合理。注意：真实比武里重甲更安全，马跑 60–100 m 几乎不受负重影响。要让轻甲成立，必须加入游戏化代价，并在文档中写明这是为了好玩 | 新增重量表（每件盔甲、头盔按博物馆数据或明确估算；盾、枪按尺寸公式），负重、疲劳和 HUD 都改用真实公斤数 |
| 重甲防御高、轻甲冲得快，轻甲能打过重甲，是技术取舍 | 方向对，但现有装备是"品质阶梯"：品质越高防护越高，没有同档的轻重选择，所以重甲天然是纯升级（同类游戏最常见的坑，见资料 D1）。另外实测发现，速度对双方是对称的：相对速度同时决定两人受到的伤害，"冲得快"本身不会让轻甲占便宜 | 让轻甲的好处在操作中感受得到：见第 2 节规则与模拟结果 |

## 2. 规则改动与模拟证据

### 规则（core/horse_condition.gd、joust_match.gd）

| 改动 | 内容 | 依据或用意 |
| --- | --- | --- |
| 真实负重 | 负重 = 骑手 72 + 马具 14 + 盔甲 + 头盔 + 盾 + 枪 + 马衣（kg） | 博物馆数据（研究文档 A） |
| 负重门槛 | 超过舒适承载的 88% 后，耐力消耗明显加快 | Powell 2008：负重达体重 25–30% 时出现应激 |
| 马速与加速 | 负重越轻越快（速度系数 0.90–1.05，加速系数 0.84–1.10） | 骑砍霸主的教训：惩罚小到感觉不到，重甲就成了纯升级 |
| 灵活度 | 护具每重 1 kg，调枪、换盾、枪身恢复慢 1.5%（0.82–1.15） | 游戏化设定，让轻甲的好处操作中可感 |
| 坐稳 | 骑手连同护具越重，越难被撞下马 | 物理惯性 |
| 冲力 | 自己马速越高，枪击越有力（全速为 1，慢或累时最低 0.6） | 相对速度对双方对称；冲力让马快、马不累只对自己有利 |

### AI 对 AI 规则模拟

- 方法：test_balance066，60 Hz 步进，每局交换出场边，60–70 局一组。
- 装备：轻甲 = 英格兰新手锁甲 + 鼻护盔（护具 17.5 kg，整备 109 kg）；重甲 = 英格兰最高级组合甲 + 闭盔（护具 34.5 kg，整备 126 kg）；马匹同为枣红马（舒适承载 130 kg）。
- 这是规则模拟，不是玩家试玩。

| 对局 | 基线 | 调整 1 | 调整 2（采用） |
| --- | --- | --- | --- |
| 轻甲老练 vs 重甲老练（同等技术） | 轻甲胜 21.5%（65 局） | 27.1%（59 局） | 25.0%（56 局） |
| 轻甲老练 vs 重甲正规（技术更好的一方穿轻甲） | 轻甲胜 77.1%（70 局） | 59.0%（61 局） | **83.3%（60 局）** |

解读：
1. **"轻甲凭技术打赢重甲"已经成立**，而且调整后更明显：技术好一档的轻甲骑手胜率由 77% 升到 83%。
2. **同等技术下重甲仍占约 3:1**。主要是进度差：拿来比较的是起步锁甲（躯干防护 11%）对最高级组合甲（40%）。伤害差 1.5 倍以上，靠速度、灵活、耐力这些小优势补不回来。
3. 调整 1 的教训：马速差拉得太陡（0.40）会打乱 AI 出枪的时机，反而害了轻甲，所以调整 2 改回 0.20，并加入冲力和负重门槛。
4. 两方都打满 3 回合，几乎没有击落，胜负靠十几点血量差决定（平均差 14–21）。这个风险见第 3 节建议 2。

## 3. 建议（按优先级）

1. **【需要你决定】给盔甲加"配置"（换件），在同一进度档提供真正的轻重选择。**
   - 每件胸甲可选：轻装（卸下臂、腿部分甲片，约 −5 kg，躯干防护 −5%）／标准／比武加强（加大护肩和护颏，约 +4.5 kg，躯干 +5%、头部 +4%）。
   - 历史依据：组合甲本来就带比武替换件（Met 22754：大护肩 1.9 kg、护颏 2.1 kg）。
   - 现有装备是"品质越高越重越防"的单一阶梯，没有同档的轻重选择；这是让"轻甲是技术取舍"成立的关键一步。不需要新美术。
2. **【需要你决定】加入计分**：断枪、击中头盔或胸甲、击落分别计分（参考历史比武计分表）。现在 3 回合打完几乎没人落马，胜负靠十几点血量差，玩家会觉得结果随机。计分让精准、灵活的轻甲骑手能靠点数获胜。
3. **品质与防护脱钩（中期）**：品质代表做工（同样重量防护更好、穿着更灵活），重量等级代表覆盖面积；高品质也提供轻甲款（例如意式布面甲、半身骑兵甲）。
4. **回合之间的选择**：让马喘口气（耐力）还是继续催马、换枪、调整盾位。疲劳规则已有，可以做成玩家能主动管理的东西。
5. **把命中原因讲清楚**：慢动作已有；结算里再显示冲力、角度和"盾挡偏"的原因（同类游戏最常见的差评是"判定像随机"）。
6. **纹章编辑器**：底色、纹章图形、颜色自选，按纹章色彩规则提示，同步到盾、马衣、罩袍和旗帜。玩家对这类编辑器需求很大，见研究文档 C4。
7. **战斗中按盔甲类别区分轮廓**：锁甲、布面甲（铆钉点）、板甲（大护肩）、蛙嘴盔的轮廓各不相同；罩袍也显示纹章。
8. **【需要你决定】马衣的非战斗收益**：例如比赛声望或观众好感（类似天国的魅力值）。现在马衣只有重量代价，在意输赢的玩家会一律不穿。按你"纯装饰"的要求，本轮没有加。
9. **疲劳表现**：马身出汗泡沫、喘气声；军械库里的负重文字可以改成色带条。

| 对局 | 调整 2（v0.4.25） | v0.4.27 |

| 轻甲老练 vs 重甲正规 | 轻甲胜 83.3%（60 局） | 轻甲胜 88.2%（34 局） |

- 资料：logs/balance068-v0427-m1.json、balance068-v0427b-m4.json。两次运行都因为整机可用内存跌破 2 GiB，被保护器提前停止，样本只有 34–35 局，误差约 ±8%。
- 胜负由什么决定：竞技场 80–97% 按比分决胜，几乎没有落马。
- **结论：轻重甲的强弱翻转了。** 计分只看击中部位，不看伤害；而重甲在竞技场里唯一的好处是减伤，所以重甲只剩代价。实战模式仍按骑手状态决胜，重甲依然有用。
- AI 收盘时臂力约 100%：AI 很少大幅晃枪，臂力几乎只影响玩家。
- **建议修正**：胸腹、头盔的一击，只有穿透护甲后的力度达到"实击"门槛才得满分，否则只算"擦中" 1 分。这样重甲能把一部分重击化解成小分，同时保留"技术好就能赢"。需要用户确认后再改，并重测。

## 4. 与同类游戏对照：我们有没有犯同样的错误

| 同类游戏的坑 | 我们的情况 | 处理 |
| --- | --- | --- |
| 重甲是纯升级（骑砍霸主） | **有**：品质阶梯，同等技术重甲约 3:1 | 已加入负重代价；根本解决见建议 1、3 |
| 属性压过技术（Rival Knights） | **没有**：技术好一档的轻甲胜 83% | 保持 |
| 命中像随机 | **有风险**：几乎没有击落，胜负靠小血量差 | 建议 2、5 |
| 疲劳是隐藏规则（天国2"马不肯冲"） | 曾有风险 | 已在军械库显示整备负重与承载、对战显示"马已疲惫·跑不满"和负重 |
| 外观装备带属性惩罚（Fashion Souls） | 马衣按你的要求带少量重量 | 已标注风险，见建议 8 |
| 纹章在画面里认不出 | **有**：盾面底色错、纹章卡片空白 | 已修：纹章决定盾面，图案按盾形裁切加描边 |
| 装备长得一样 | 部分有 | 图标已放大；盾牌按做工分级；战斗中盔甲轮廓区分仍有限（建议 7） |
| 比赛重复、没有风险 | 有风险 | 建议 2、4 |
| 没有练习模式 | 没有这个问题：已有练习场 | — |
| 氪金或刷数值 | 没有 | — |

真实与好玩冲突的地方：轻重取舍的规则是游戏化设定。真实的野战甲几乎不拖慢骑手，比武甲（25–48 kg）更是越重越安全。这一点已写入 DESIGN_DECISIONS。
