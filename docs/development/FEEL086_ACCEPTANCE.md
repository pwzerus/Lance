# FEEL-086 动作、实战结果与玩家反馈验收

日期2026-11-10；基线v0.4.39-r2 / 8cd9935；开发窗口23:14 UTC至次日05:14 UTC。

## 依据与边界

没有查到“达成若干数字即可认证为优秀独立游戏”的统一标准。以下将公开评审维度转成GALUMU的验收条件；工程通过是交付底线，不能替代用户觉得自然、有力、有趣。

- [IGF官方竞赛规则](https://igf.com/igf-competition-rules/)分别评价设计执行与平衡、视觉表现、声音等，不提供万能分数线。这里只借用维度，不声称参加/通过评奖。
- [AGDA 2020官方评审表](https://gcap.com.au/wp-content/uploads/2020/07/AGDAs-2020-Judging-Criteria.pdf)关注风格一致、动画与绑定协调、控制与物理一致、清楚反馈和再玩意愿。它是2020年的评审参考，不冒称2026强制规范。
- [GDC：Game Feel: Why Your Death Animation Sucks](https://gdcvault.com/play/1022759/Game-Feel-Why-Your-Death)公开介绍强调交互、动画、声音、画面构成共同构建反馈。本轮阅读公开介绍，不声称看完演讲视频。
- [GDC：RDR2可信马匹](https://www.gdcvault.com/play/1027113/AI-Summit-Making-the-Believable)公开介绍将马的可信表现视为体验核心；不是“增加骨骼数就会自然”的证明，也不宣称复刻其技术。
- [Xbox XAG117](https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/117)：保留可关闭震动等运动效果；不通过强闪烁、持续晃屏代替受力。
- [Steam构建审查](https://partner.steamgames.com/doc/store/review_process?language=english)是功能与发布检查，不是好玩认证。
- [骑手生物力学综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC10741103/)用于理解骨盆/躯干协调与步态差异；本项目像素坐标/振幅/伤害值不是实测人体或马匹数据。

## 交付门槛

1. 不允许已复现的脱节/瞬移、三次清晰有效重击无解释地存活、无限抖动、重复伤害、崩溃留作已完成。
2. 保留失败证据，先写原因再改；规则数值与工程阈值明确是游戏设计。
3. 规则模拟、引擎输入、连续渲染、OS输入、真人反馈分别报告；不冒充用户验收。
4. 最终独立发布包实际运行、源与包一致、旧包保留，提交现分支并核对GitHub SHA。
5. 时间用于发现与修复，不靠重复已经通过的测试耗满；主观体验仍以用户反馈为最终依据。
