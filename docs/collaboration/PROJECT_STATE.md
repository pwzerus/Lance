## 玩家控制与规则

鼠标上下调枪尖；按住左键/空格催马，松手下一物理步开始惯性减速；不保留短按两秒缓存。1/2/3护头/胸/腹，右键/Q循环；W/S前倾25°/后仰45°；Esc暂停，R重开，F11全屏，H调试范围。盾按钮不催马，失焦取消按住并暂停。

巡航210、疾驰480乘马匹倍率，起跑0；催马加速度500，自动起步180，减速220，命令变化率2000。半秒巡航对照：释放前进105，催马前进143且末速约400，属于游戏单位。耐力与十匹马速度/稳定取舍沿用。

竞技场非致死、每轮新枪不回血；实战允许死亡且断枪跨轮，整体更不易断。血腥只改表现。三档AI、三轮结算、练习、商店、自动存档/三手动槽沿用；无刀剑或近战。四国72骑枪、各24甲胄/头盔/盾和10匹共通马，历史年代/身份不等同品质等级。

## 本轮动作和速度感

马腿根对应肩与臀，前后近端骨方向独立；UPPER/LOWER均68。宽度独立于长度缩放，单张上腿纹理在hip→proximal→knee间连续蒙皮，根部由身体遮挡，避免细竹竿与圆形贴片。原atlas复用，无新位图生成。

四档高度差约3/6.5/10.7/15.1，疾驰较旧约30.4减半；俯仰与骑手滞后也减弱，保留承重/腾空时序、颈尾随动及可预判枪线影响。起步时旧摆腿秒数缓存会过预测落点，现按当前频率和剩余连续相位计算。世界锁脚、连续腿周期、固定骨长与重轮清理保留。

倒计时先交代双方，再提前落到玩家跟随镜头；用屏幕位置插值防止缩放期间裁切。远段稳定.82倍率，间距2800→1800恢复双骑，早于1100瞄准承诺区；近身有限放缓、实际命中反馈保留。地面/栅栏世界固定，背景较慢视差，尘土只在真实落蹄时出现并分跑道遮挡；风声与蹄声随真实速度，合成音而非实录。结果覆盖后停止后台跑出。
