# de_helmet_4 built-in imagegen prompt

Use case: historical-scene. Asset: ONE isolated modular helmet for GALUMU. Reference image is only pixel-art technique: chunky stepped pixels, 10-16 shade groups, blue-grey steel with dark outline, readable broad highlights. Its SHAPE is different and must NOT be copied. Make one complete helmet, three-quarter view facing RIGHT and partly to viewer, centered square, genuine transparent background, no head/human/skin/eyes/neck/shoulders/mannequin, no labels/text/floor/shadow. Large clean pixel blocks, no fine texture noise. Subject German Nuremberg Maximilian CLOSE HELMET around1520, inspired by actual Met49.163.1. Rounded compact skull with many parallel vertical FLUTED CHANNELS, rounded narrow upper visor and distinctive BELLOWS visor with 3-4 horizontal projecting shallow ridges stacked across the face. Short compact nose profile, continuous hinged chin defense and 2-3 neck lames. Dense fluted ribs follow skull like fan, strongly visible at70px display. All steel-grey, NO gold, NO plume. Not smooth armet, not flat barrel greathelm, not a projecting long dog muzzle.

Historical photo actually inspected separately; imagegen could not decode the museum reference file through this environment, so only the existing project style image was supplied. This is an original game adaptation, not a pixel tracing of the historical object.
