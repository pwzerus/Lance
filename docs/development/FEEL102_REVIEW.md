1. 首次GPU复用旧夹具时，没有等待新的分帧准备完成，访问了未生成的声音/骑手节点。修正测试等待presentation_ready再执行；保留feel102-before失败记录，不能把它写成游戏运行崩溃。修复后before02有效。
2. 初次脚本批处理未等待长测试结束，后续四次启动被单实例保护拒绝；没有并行运行两个游戏。改为逐个等退出，再重跑02批次。AI首轮80秒预算不足被保护器终止，改用60Hz测试、进度落盘和240秒预算，balance02完整42例正常结束。保护阈值未改。
3. 新压力测试继承了旧_initialize，初次实际跑的是旧规则门禁；补上显式入口后才执行新压力断言，不把那次旧门禁冒称新测试通过。
4. 旧的“胸部不落马”视觉夹具不适用当前规则：满速胸击会耗尽平衡。即使提高坐稳阈值也仍会因平衡落马，已用明确的高平衡QA夹具隔离在马反馈。未因此削弱真实胸击。
5. 默认受限运行无法创建用户渲染缓存；后续获准后台运行仍经过同一保护器/隔离桌面，渲染缓存错误消失。不关闭保护或切到前台。
6. 静态复核补足共享反馈函数的非有限/非数字输入保护，防止异常可选事件值污染镜头/音量。真实规则事件不依赖这个兜底计算伤害。
