# REQ-050：撞击、完整落马与整马形体，两阶段需求

2026-10-29；基线80ee402，当前发布v0.4.9，分支codex/v0.4。用户本轮只要求整理需求与阶段，等待另行指令开始开发；没有新的开发时长授权。本文件不是已完成功能清单。

## 本轮玩家反馈

- 撞击像轻微的“当/叮”，冲击感比期望弱。火花与目前的声音不足以表达骑枪高速碰撞；希望参考Bloody Bastards的力度和不同碰撞声响。
- 人物死亡像骨架被拆散，切换表现时有肢体消失。可以夸张地被掀飞、侧倒或落地，但必须始终像完整的人；不同受击部位、方向与力量应带来不同反应。
- 马身与腿的接缝有改善，但马腿折叠像鸡腿/蛙腿，根部仍显得长在腹部；马头颈与身体仍有分离、拼接感。需要重新设计整匹马的形体与运动结构。

这是玩家对当前体验的否定性反馈。DEV-049的程序/渲染检查历史保留，但不据其“通过”判定上述体验问题已解决。本轮仅静态阅读相关代码，没有再次运行游戏或听取对照音频。

## 阶段一：恢复有重量的撞击，重做完整人物的受击与落马

### 1. 撞击声与受力反馈

目标是让玩家明确感到“骑枪带着速度撞上了人或装备”，并听懂撞在哪里、撞得多重。

- 按**实际命中部位、接触材质、力度**组织声音：盾牌、头盔/头部、胸甲/躯干、腰腹等应有可辨差别；轻擦、格挡、重击、断枪不能只是一种小叮声的音量变化。
- 声音需要清晰的接触瞬态、厚实的受力主体与适量余响；相同类别可有少量变体，减少机械重复。避免尖锐提示音盖过重击主体，也不靠削波失真或一味放大总音量。
- 声音、角色受力、枪盾反作用、短接触停顿和镜头响应必须在实际接触时同步。火花帮助读位置，人物/装备的受力表现承担重量感。
- 保留冲锋逼近、有限近身放缓和命中后的释放。强弱反馈有差别，擦过/未命中不能演成重击；长慢动作不能把关键碰撞拖成轻轻碰一下。
- Bloody Bastards作为后续观察与听感比较对象，本轮没有新竞品研究成果；素材方案在实施阶段确定，不把已有合成音自动认定为足够。

### 2. 完整人物与落马差异

- 人物受击→失衡→脱鞍→腾空/侧倒→落地，必须连续承接当时姿态、位置与速度。保留同一个人物的脸、装备、身体比例和全部肢体。
- 头颈、肩肘腕、髋膝踝维持合理连接与活动范围；不能像爆炸一样拆成独立零件，也不能用隐藏肢体来解决穿模。
- **切换前后不得出现肢体突然消失、跳位、换成不匹配旧模型或一帧重复身体。**近远遮挡与左右朝向同样检查。
- 根据真实命中部位、方向、冲量和当时骑乘状态决定反应。建议表现类型包括上身后仰带动失衡、躯干受力后翻/侧倾脱鞍、腰腹受击折身侧落；这些是待实现验证的动画方案，不是保证对应某种真实医学死亡机制。
- 落地要有承重、有限翻滚/滑动与停稳，不能无限旋转或反复弹飞。不同“死法”指受击到落地的可辨动作差异，不是仅替换一张尸体图，也不是新增肢解。
- 竞技场仍非致死，可失衡/落马；实战允许死亡。关闭血腥仍保留完整受力与落马动作，不能改变死亡、伤害、胜负规则。

### 当前实现的静态依据

`sound_bank.gd`与Battle目前以impact/shield/break等大类播放，非盾部位共用impact；缺少完整的部位/材质音色对应。`impact_fx.gd::fall(fighter,direction)`没有接收实际部位、接触点和冲量，使用固定抛出速度及随机转速，创建六块分件，关节主要直接连躯干。骑乘人被隐藏后换成旧肢体素材。这些是必须优先诊断和改进的位置，不宣称本轮已动态复现每一种故障。

### 腿部的范围说明

用户举了头、胸、腿的不同声音/反应作为期望。目前规则只有head/body/flank/shield，**没有独立腿部命中区**。先把已有实际部位的差异做好；“可单独击中腿部”另列为需确认的规则扩展，不把腰腹冒充腿，不凭空播放腿部命中声。若后续纳入腿部，需要同时设计判定、保护/反制、伤害与提示，不能悄悄引入一套未经确认的平衡改动。本计划不新增马匹受伤系统。

### 阶段一验收

1. 在相同设备与音量下对比当前包和候选：轻擦、盾挡、头盔/胸甲重击、断枪能听到层次；音量提升本身不算完成。
2. 观察完整连续片段及转换前后逐帧：命中前、受力、脱鞍、落地；头、躯干、双臂双腿始终连续，没有骨架散开或可见肢体凭空消失。
3. 对照不同实际部位、方向、弱/强冲量，落马方向与受力相符，不是每次同一个飞行轨迹加随机转速。
4. 竞技场/实战、血腥开/关、左右骑手、不同甲盔外观、暂停/重开/结束都不破坏身体与规则。枪盾仍有限速移动，不瞬移。
5. 保留连续实机音画证据和失败记录。自动测试证明规则/连接，玩家试玩判断冲击感；两者分开。

## 阶段二：重设整匹马的形体、连接与自然步态

### 1. 先统一整马结构，再拆件和驱动

- 以整匹马为设计单位，统一头、颈、胸肩、躯干、后躯及四肢的比例、轮廓、明暗和像素尺度。
- 头接颈、颈接胸肩应有连续体积，不能像头被粘在躯干上；转动、俯仰、加减速时也要连着。
- 前后腿根与肩部/后躯的视觉位置一致，不能显得从腹部中段垂下。不能只改贴图遮住错误关节或把腿拉长。
- 前后肢分别设计关节折叠、段长、粗细与活动范围。纠正鸡腿/蛙腿式轮廓；真实参考应区分不同关节，不能把马腿简化成人腿或反向折线。
- 先看统一整马样张和关键动作轮廓，再生成/调整游戏分件与绑定；内部可以继续分件或蒙皮，但游戏里必须看起来是一匹完整的马。

### 2. 用正确形体重调动作

- 静止、慢步、小跑、疾驰以及起步/加速/松手减速都以新结构检查，动作不能把正确静态图再次扭成怪形。
- 保持落蹄、承重、离地、收腿和前送的连贯关系；马身、头颈与后躯的运动一起协调，不能只是横移身体和摆腿。
- 保留之前改善的有限起伏，不靠重新加大弹跳制造速度。支撑蹄贴地、不明显滑步，摆动蹄有合理离地与落脚。
- 保留骑手跨坐、鞍座/腿的关系、两匹马隔栏两侧的遮挡，以及可预判且适度影响枪线的起伏。不改成全3D或随机偏枪。

### 当前实现的静态依据

头颈仍沿旧HorseArt分段，躯干/上腿来自新HorseSkin，下腿继续用旧分件，骨点与弯曲沿旧gait。统一皮肤解决了一部分黑缝，却不能自动纠正关节位置、轮廓和头颈体积；这一阶段需要统筹形体、绑定与动作，而非再次只覆盖接缝。

### 阶段二验收

1. 左右两个方向的站姿与慢动作中，前后腿根、长度、粗细与折叠都像同一匹马；头颈胸肩连续。
2. 连续播放慢步、小跑、疾驰及加减速，观察全身和近景；不再出现明显鸡蛙腿式收折、断颈、漂脚或剧烈反常弹跳。
3. 骑手、鞍具、马身和四肢在实际远近镜头都不脱节，前后跑道分层保持。
4. 通过后复验第一阶段的撞击和完整落马，防止新鞍座/马体比例破坏人物转换。
5. 交付实际可运行包、连续对照画面、审查与剩余问题；不以单张漂亮图、骨长检查或测试数量证明自然。

## 执行边界与顺序

建议先阶段一（撞击与完整人物），再阶段二（整马形体与动作）；每阶段各自验证、修复、保存检查点。具体时间由用户后续指定。本轮仅记录，不开始改代码、生成素材、跑测试或导出。

沿用像素风、装备装饰、有限速枪盾、原有模式与存档规则，无刀剑/拔刀近战。后续实现继续在原工程上诊断改进；需要替换的表现模块应说明原因与兼容接口，而非重写整个玩法。QA隔离、旧包保留、版本分支与逐功能提交继续执行。
