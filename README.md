# 骑枪与桂冠 · Lance & Laurel

Godot 4.5.1 + GDScript 的 Windows 单机试玩版 v0.4。项目依据原始 GDD、`DESIGN_DECISIONS.md` 和历史考据档案开发；本轮根据桌面输入记录重调催马、减速与镜头，修复练习入口遮挡。

## 开始试玩

根据玩家“加速变化太小”的反馈，新版点按约0.45游戏秒升到疾驰，维持催马2游戏秒，松开后逐渐减速。OS级桌面点按已取得速度变化记录，长按3游戏秒在引擎内验证；不将工具的短按/拖动称为真人长时间试玩。详见 `docs/development/V04_REVIEW.md`。

双击根目录 `Play-Latest.cmd`，或打开 `builds/LanceAndLaurel-v0.4/LanceAndLaurel.exe`。窗口标题和首页底部显示 v0.4。旧发布目录保留；不需要安装 Godot。

`LanceAndLaurel.pck` 必须与 EXE 放在同一文件夹。移动或分享时，复制整个 `LanceAndLaurel` 文件夹，或使用其 ZIP 试玩包。

新版第一次出战会显示操作说明。建议先进入“练习场”：盾位按轮次高低交替，底栏标记已尝试的操作，不计职业输赢、不发奖励。

| 操作 | 效果 |
| --- | --- |
| 上下移动鼠标 | 调整枪尖高度；停住压稳，大幅变招会失稳；镜头自行缩放时保持原角度 |
| 按住左键 / 空格，或点按左键 | 按住持续加速，点按催马2游戏秒；倒计时内点按保留到冲锋开始，松开后逐渐减速 |
| 右键 / Q | 高低盾切换：高盾护头，低盾护腰腹；切换约0.36游戏秒，另一处暴露 |
| W / S，或上 / 下方向键 | 前倾架盾约 25° / 后仰约 45°；姿态带惯性 |
| H | 显示 / 隐藏实际受击范围，默认关闭 |
| Esc | 暂停与血腥、震动设置 |
| R | 重新比赛 |
| F11 | 切换全屏 |

设置中可启用纯鼠标倾身：滚轮调节，中键回正。马匹始终自动前进。战斗没有准星、轨迹线或瞄准吸附。

长距离冲锋快速起速，镜头保留可见的接近运动，最后一小段有限放缓，接触后短暂顿帧、碎片飞出，交错后拉远。可在设置关闭接近放缓及命中慢动作。底栏区分催马、减速中与巡航，显示游戏速度和耐力；速度不是历史实测公里时速。上栏显示盾位、盾耐久、枪稳和平衡；命中后显示实际部位及盾破损。高盾可挡高枪，但露出腰腹。后仰可避开已承诺的高枪，同时削弱自身攻击并降低平衡。

## 现在可以玩什么

- 对 AI 的最多三次骑枪对冲；落马或失去战斗能力提前结束，打满三轮比较骑手剩余 HP。同时败北或相同 HP 为平局。
- 竞技场非致死，每轮自动领取新枪，换枪不治疗骑手。实战允许死亡，断枪与残柄保留到本局结束，较低的断裂倾向与竞技场分开配置。
- 落马关节物理、受击回摆、断枪、木屑、慢动作、顿帧与震动；血腥默认关闭，开关不改变死亡、伤害或胜负。
- 四条地区收藏线、34 件装备、银币购买、装备、声望与五个年代窗口解锁，以及自动存档和备份恢复。
- 独立生成并接入的三分之四骑手、马匹、六张美术源图；不同年代胸甲与头盔轮廓、四种几何盾徽、两种场景，以及合成音效和旋律。
- 游戏内历史手记及出处链接；完整考据记录在 `docs/HISTORICAL_RESEARCH.md`。

从 1100–1300 主题窗口起步，后续解锁门槛为 6、16、30、48 声望。胜利获得 180 银币、3 声望；平局 110 银币、1 声望；败北 55 银币、1 声望。实战另加 30 银币。死亡只终止本局，保留装备收藏。对手使用独立的年代配装，AI 有三档反应难度。

## 存档

游戏通过 Godot 的 `user://` 路径保存，不写在 EXE 旁边。Windows 默认目录为：

`%APPDATA%\Godot\app_userdata\骑枪与桂冠 · Lance & Laurel\`

主存档为 `profile_v1.json`，备份为 `profile_v1.backup.json`。关闭游戏后复制这两份文件即可备份。自动验收使用单独的 `qa_` 文件，不改动正式玩家存档。

## 当前边界

这是早期可试玩版本。伤害、冲击指数、断枪概率、价格和解锁门槛是游戏参数；不是历史伤亡统计或连续材料仿真。实战抽取两名骑手相遇的片段，固定分道、隔栏与三轮规则属于游戏改编。

已制作不同年代的胸甲与头盔，四肢、马具、部分罩袍仍共用基础分件，尚未逐件完成历史多角度结构复核。跨时代自由拼装不称为同期原装复原。马匹目前采用分件程序步态；还需人工逐像素整理、专业步态和落马动画打磨。

装备数量、地区专属装饰、马衣马铠、纹章与文书印章的完整体系仍需扩充。暂未加入联机、军团战、战役剧情、肢解、永久伤残、存档云同步或安装程序。音效是原创合成版本，尚未做正式混音。真实手机触控和其他 Windows 机器尚未验收；本轮在本机 Intel OpenGL Compatibility 环境运行验证。

## 开发与验证

Godot 编辑器打开 `game/project.godot`，按 F5。便携引擎在 `tools/godot-4.5.1/`，Windows 发布模板在 `tools/templates/`。

源码 ZIP 不包含引擎、导出模板和发布包。移动到其他机器时，请准备 Godot 4.5.1 与 Windows 导出模板，并在导出设置中调整自定义模板位置。

主要代码：`core/joust_match.gd` 为可独立模拟的规则，`battle.gd` 负责输入、AI、时间效果和场景，`visual/` 为分件与反馈，`main.gd` 为界面，`core/game_state.gd` 为进度和存档。装备在 `game/data/equipment.json`，美术来源与完整提示词在 `game/art_sources/ASSET_MANIFEST.md`。

复现命令与验收证据见 `docs/development/VALIDATION.md`；本轮审查见 `docs/development/V04_REVIEW.md`。发行包附带 Godot 与依赖许可、Noto Sans SC 字体的 OFL 许可。当前沿用的像素美术记录在 `game/art_sources/PIXEL_V03_MANIFEST.md`。

v0.2 专项记录见 `docs/development/V02_REVIEW.md`；动作反馈工作流见 `skills/joust-game-feel/SKILL.md`，包含查阅资料和适用边界。

玩家体验测评工作流见 `skills/game-experience-critic/SKILL.md`；竞品与40条公开评论记录分别见 `docs/JOUSTING_GAME_BENCHMARKS.md`、`docs/PLAYER_FEEDBACK_RESEARCH.md`。评论用于提出设计假设，不代表全体玩家意见。
