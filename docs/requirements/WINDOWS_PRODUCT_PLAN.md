- 第8项结算解释实现约束：落马原因读取真实致命/受伤/冲击/平衡事件；非终止的伤势结算若给建议，要按玩家实际承受部位和伤害汇总，而非只取最后一击猜测。无接触不能说命中了某部位；双方落马仍需同时描述。比分、准确奖金额是必要信息，不把完整属性数字重新塞回默认页。

- 第6项：关卡对手的stats目前没有显式人物appearance，可能都用同一回退面容。需核对实际渲染，再决定按稳定的关卡身份分配已有脸型/胡须等，保持纯装饰与头盔适配，不改变碰撞。
