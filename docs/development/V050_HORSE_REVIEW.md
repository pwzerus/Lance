## 原因与修正

旧骨架的前后肢下部都使用 68+68 的等长两骨，且上段肘/膝位置基本固定。旧前肢站姿肘至球节距离约 112，但两骨总长 136，因此前腕静止时已经被迫明显屈曲；统一皮肤只能填缝，不能修正这种轮廓。头颈、躯干和下腿还来自不同代分件，根部与像素尺度缺乏统一基准。

本轮沿用原 `body()`、步频、触地顺序及 `leg()` 调用接口，使用同一整马母片的骨点与分段长度。保留 saddle `(-18,-168)` 和蹄底 ground `12`；前后肢区别如下：

| legacy 输出键 | 前肢近侧 | 后肢近侧 |
| --- | --- | --- |
| hip | 肩 `(72,-134)` | 髋 `(-99,-148)` |
| proximal | 肘 `(53,-97)` | 真膝/stifle `(-86,-104)` |
| knee | 腕/carpus `(54,-52)` | 飞节/hock `(-134,-58)` |
| ankle | 球节 `(53,-11)` | 球节 `(-132,-14)` |
| foot | 蹄底 `(65,12)` | 蹄底 `(-119,12)` |
| 四段长度 | 41.593 / 45.011 / 41.012 / 25.942 | 45.880 / 66.483 / 44.045 / 29.069 |

远侧有投影偏移，经过解析链求解后同样将蹄底置于 ground 12。使用 `rest_foot(index)` 取落脚基准、`segment_lengths(front)` 取真实段长；不再将所有腿断言为同一 `Gait.UPPER/LOWER/PASTERN`。主负责人已将 Rider 的预测落脚位置改为新基准，继续使用原有世界锁蹄、步态过渡相位和重开缓存处理。

解剖依据是 [UMN 兽医前肢教材](https://open.lib.umn.edu/largeanimalanatomy/chapter/thoracic-limb-forelimb/)、[后肢教材](https://open.lib.umn.edu/largeanimalanatomy/chapter/pelvic-limb/) 对肩/肘/腕、髋/膝/飞节及后膝—飞节联动的区分；[UMN 外形教材](https://extension.umn.edu/agriculture/animals-and-livestock/horse/conformation-of-the-horse) 支持高接胸肩的颈根及前后管骨区别。[IFCE 步态说明](https://equipedia.ifce.fr/en/equipedia-the-universe-of-the-horse-ifce/equestrian-instruction-and-teaching/didactics-and-equestrian-techniques/interdisciplinary-principles/the-horses-gaits-definitions-and-figures) 用于核对慢步、对角小跑和非对称跑步/疾驰的序列。这里的坐标、股骨限位和折叠幅度是游戏绑定取舍，不是临床关节活动度或实测动作捕捉数据。

`whole-horse03` 是前蹄过冲最终修复前的蒙皮观察。最终动作的 `whole-horse04` 由主负责人继续渲染复核，本审查不预填其通过结论，也不以旧图证明新轨迹已获自然感认可。

新整马路径没有再单独旋转旧蹄图，**这不是漏用了 toe_angle**：

1. Gait 以 `ankle = foot - pastern.rotated(toe_angle)` 定义球节与蹄底关系。
2. HorseSkin 最后一个变换把源图 `fetlock→sole` 映射到当前 `ankle→foot`。
3. 蹄与系部因此已随该轴旋转；另外再按 toe_angle 旋一遍会重复施加角度。

`foot` 是蹄底挂点，不是球节点。现有几何检查只保证该挂点接地；一条轴对齐不能独立证明蹄子整个不透明边缘都在地面上。源脚底轮廓、纵横缩放差异、蒙皮混权和实际镜头像素取整仍需图像检查。

### 十马回归：catalogue-anatomy-01 的度量误报

完整 [catalogue-anatomy-01](E:/GALUMU/docs/development/logs/v050/catalogue-anatomy-01.json) 已由主负责人运行结束。只有 courser/e3 的双方向 120Hz 关节世界速度超限，共四条；其余骨长、形状、脚、滑移及 toe 检查通过。courser 原始关节峰值约 2693.898，e3 约 2652.149；默认 bay 同相位约 2507.328。三者的最差点均为前远腿 2、swing 约 0.38 的腕，前后关节记录没有重现原先肘部 pole-angle 塌陷。

原检查把整匹马的水平平移也算入关节世界速度，却将以疾驰 480 调定的绝对 2600 上界直接用于 595.2 / 566.4。该值是游戏连续性检查，不是关节生理速度上限；更快马的刚体平移不应自动算成局部关节尖跳。此处修的是测试度量，**没有据此修改生产步态或降低马速，也不称为修复了游戏动作 bug**。

修订后的测试仍保存原始 `maximum_joint_velocity` 与逐点证据，仅将超过参考运输速度 480 的 `body.x` 平移分量从当前关节位移中扣除，以同一个 2600 上界检查 `maximum_reference_joint_velocity`；不会按马匹速度倍率缩小内部关节动作。另将全部 body.x 平移扣除后独立要求 `maximum_local_joint_velocity≤2600`，保留骨角、蹄速度、锁蹄和 toe 的原判据。≤480 配置的关节参考检查不变，因此旧默认马的 2655 肘部故障仍会被抓到。原始失败报告保留。

### 新局部检查抓到的真实临落地故障

[catalogue-anatomy-02](E:/GALUMU/docs/development/logs/v050/catalogue-anatomy-02.json) 全十马的参考世界速度均通过，但新增局部检查抓到 e3 双方向 120Hz 超限，峰值约 2613.032。[catalogue-anatomy-03](E:/GALUMU/docs/development/logs/v050/catalogue-anatomy-03.json) 对 e3 的六组变速诊断补充了 `worst_local_joint`，确认这次是前远腿 2 的肘、swing 0.889→0.909；当时马速已降到约 429.094，前蹄世界位置反向退约 9.54，而马体前进约 3.58，肘局部转约 29°/8.3ms。此处发生于低于参考 480 的速度，不能用高速运输解释。

原前肢 `_swing_point` 在 0.75 时刻使用 `reach+12`，使 Rider 的前送比例大于 1：先越过预测的世界落点，再在最后一段拉回。短的新前链会先被拉至接近共线的最大伸展，回拉时解析肘角快速增大，形成局部尖跳。

本次仅将前肢水平前送改为从 `-reach` 到 `reach` 的单调五次 ease，端点速度/加速度为零；保留原抬腿 y 曲线、步态序列、body 起伏、世界锁蹄与所有马匹速度。新增前送不越界、不从过冲落点回拉的契约检查，不对照具体多项式。保留新增 local≤2600 及参考 world≤2600，修复后默认和全十马复跑均通过；没有通过删除新增检查来消除失败。
