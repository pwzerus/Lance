# de_helmet_3 built-in imagegen prompt

Reference image is only pixel-art technique: chunky stepped pixels, 10-16 shade groups, blue-grey steel with dark outline, readable broad highlights. Its SHAPE is different and must NOT be copied. Make one complete helmet, three-quarter view facing RIGHT and partly to viewer, centered square, genuine transparent background, no head/human/skin/eyes/neck/shoulders/mannequin, no labels/text/floor/shadow. Large clean pixel blocks, no fine texture noise. Subject German SALLET AND SEPARATE BEVOR of1480 inspired by Met29.158.6a,b, actually inspected. Smooth rounded skull flowing into a long slightly flared tail at nape, low central keel, front swept lip; separate tall curved chin guard below forms a broad shieldlike outward-flared lower face/neck plate. A thin horizontal sight gap between skull and separate bevor. The separate lower plate is NOT a hinged pointed visor. Near-vertical face profile, NO long nose, NO hounskull, NO comb, NO gold, NO rows of breathing holes. Smooth late Gothic clean surfaces, small sparse functional rivets.

Historical photo actually inspected separately; imagegen could not decode the museum reference file through this environment, so only the existing project style image was supplied. This is an original game adaptation, not a pixel tracing of the historical object.
