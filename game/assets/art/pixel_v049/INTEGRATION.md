# v0.4.9 连续马体集成

实际运行使用 `horse_continuous_skin_v049_02.png`，01为保留的生成阶段。原始alpha不做改写；`mounted_pixel.gdshader`在运行时丢弃alpha<.5的提取光晕。图02不是历史实物复原，也不是人工逐像素作品。

`visual/horse_skin.gd`采用原始1536×1024画布上的实测HIND/FORE挂点。马体源矩形(120,50,1285,595)映射到(-155,-188,247,106)，鞍座和背部跟随原有刚性躯干，肩/臀下缘渐混到近侧上腿。运行采样下缘截止950，略去原母片切口黑边；腕/跗以下覆盖到原下腿24%，横宽渐窄到72%，下腿先绘制。

远侧上腿使用同图的独立区域，位于马体后方。近/远腿不是改变骨长或挪马蹄；全部沿用已有horse_gait与世界锁蹄状态。固定UV、权重和拓扑缓存，只更新ArrayMesh顶点缓冲。

实景与四档步态/加减速/双向检查见 `docs/development/V049_REVIEW.md` 和对应skin05/scene02证据。参数是游戏美术绑定值，不是马匹解剖测量。
