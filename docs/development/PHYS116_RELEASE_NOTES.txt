骑枪与桂冠 · Lance & Laurel — v0.5.0-c4
Windows 开发预览

本轮修复
- 修复六种极端姿势的长时间尾摆，落地后由重力、支撑及关节耗能继续收势，不指定最终躺姿。
- 修复盾缘、靴口形成的假支点，以及小腿竖起不落下的问题；改善深折叠与脚掌支撑判定。
- 降低胸甲绘制、靴面投影和轮廓计算的重复开销。贴图、网格、碰撞点和120Hz物理频率保持。
- 保留枪盾有限移动、马匹动作及原有正式存档格式。

启动
运行完整文件夹外层的 LanceAndLaurel.exe。内存、CPU、单实例、系统余量保护保持开启。
不要直接运行 runtime 子目录中的程序。

边界
本包为开发预览，后台验证记录见 PHYS-116 交接。自动测试不等于真人自然度、手感或声音认可。
二维近远肢体仍可能在画面上叠合，部分姿势由手臂支撑成半卧。重甲与双人落地仍需进一步向稳定60FPS优化。
旧包保留；默认稳定版入口不变。
