# BALANCE-103：第24关与周边难度过渡

2026-11-17纽约，Codex。实际基线c7028aa08a7ccf03627aec5baabda6bde411844b，origin相同；历史三份差异和旧QA/UID保留，没有新Claude功能。用户要求后台、保护开启，调顺24关周边并导出/推送，保留高低枪与简单前期。

## 已查明的原因

1. 第20关冠军和第23/24关普通对手均为重甲+品质2粗枪+更稳马匹+重盾，装备防护达到品质3。第21关同时开始每轮一次变线，第23关又升级全套装备；并非只有一个AI精度参数造成难度跳变。
2. 同一品质1长枪/轻盾/灰马、600ms一次操作、两侧、追头/看盾空当代理：原第20/23/24/27关各0胜4负，18关4/4，21/22/25/26各2/4，28关3/4。重枪常先击盾心，玩家第二、三轮平衡耗尽；“盾牌挡住了”不等于没有承压。此代理不代表真人胜率。
3. 首次只拆分装备升级、减少变线轮次，23关仍0/4、24关0胜3负1平，说明不能把改完参数就称作修好。第二次用正常催马/收缰控制降低重枪进攻节奏，20/23各1/4、27关2/4，但24关仍0/4；保留完整失败/中间结果。

## 最终实现与边界

- 第24关从连续第二位重甲骑士换成均衡骑士，作为重甲教习与第25关实战之间的一场过渡；地区、关卡ID、奖励、解锁和已有存档保持。
- 第18–30关装备升级拆开：至24关骑枪最多品质1、25–30最多品质2；至26关马匹按旧品质1阶段选取，之后至30按品质2；21–26普通对手不额外叠加高一档头胸甲。保留每件装备真实数据和美术，不加隐形减伤。
- 第18–28关采用共同的pressure_ease教习节奏，29–39逐关退至0，40关起原节奏：通过原催马/收缰和速度滞回实现，不直接写速度，不改统一命中/伤害/马匹运动。不是重复加入入门training，原训练曲线不变。
- 21–24关只有第二轮提前变线，25–28关第二/三轮变线，29关起原每轮一次；其余轮仍有高低枪，只是提前亮出后定线。枪盾仍经有限控制和原观察延迟，错过窗口不临近接触硬切。
- 前17关（尤其1–5）和40–80关的数据/AI行为进行旧源码对照；自由对战无新配置时原行为保持。旧伤害、声音、马步、美术与资源保护未改。
