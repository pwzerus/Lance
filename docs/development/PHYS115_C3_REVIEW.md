# PHYS-115 c3 续验审查与交付记录

本记录接续 ca6ae4c 与 c2，独立 c3 已导出并复验。核心实现仍是同一个身体从骑乘受击连续进入离鞍和落地；本次没有重写 Claude 的基础模型。

## 变更与原因

- 靴面接触保留原三角网格、全部采样点及 120Hz 固定步；缓存不变样本并复用缓冲。六条交替运行轨迹与参考实现误差为 0；受测计算约减少 14.65%，不等同于实际帧率提升。
- 腕部与盾带增加有限弹性及相对摆动耗能。反作用仍传至前臂，不把整条手臂锁住，不设落地姿势或定时冻结。几种增加一般肩肘摩擦的方案在完整回归中出现新失败，均未采用。
- 特写中的背景原来固定在屏幕上，远侧接地线会高于背景地面。候选按远侧跑道实际投影安排背景覆盖范围，保留原素材，不移动人体或物理地面。
