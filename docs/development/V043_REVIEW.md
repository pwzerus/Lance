## 玩家可见变化

- 首页保留开始游戏、存档／继续进度、军械库、历史手记、设置、保存并退出。模式与难度放在出战页；旧收藏和自动进度继续使用。
- 初学骑手、正规骑士、老练对手使用不同观察延迟、思考间隔和压枪／收盾时机。老练对手会先展示来枪方向再变招，下一轮参考上一轮来枪。难度不增加生命、伤害或装备数值。
- `1 / 2 / 3` 直接选择护头、护胸、护腹；右键／Q 循环，屏幕按钮可点／触。盾仍连续移动，不能瞬移到目标。没有新增刀剑、近战或六自由度盾控。
- 枪尖菱形、部位角标和文字显示“当前枪线”。头部珊瑚红、胸部青、腰腹橙、盾牌金、偏离灰；颜色同时配文字。它按当前姿态估计，不预知对方下一步，也不替玩家瞄准。
- 真正接触后才出现部位色火花／冲击环。双方同时命中分别显示两条反馈；结算隐藏战斗操作栏。
- 盾面朝对手收窄、带木边厚度和后侧握带；三种盾形共用视觉／预览／碰撞轮廓。沿用已有像素资产，没有把程序变形称为逐帧手绘。
- 三个手动进度槽、原有自动存档及备份。保存收藏、装备、设置和养成；不保存对冲中途的位置。写入失败不退出，读取失败不替换当前内存进度。

## 体验判断与下一步

当前改动补齐了“选择难度 → 读盾与枪线 → 确认实际命中 → 看原因重开”的信息链。它减少猜测，不证明游戏已经足够有趣。最优先的后续证据是玩家是否能在两三局内主动用三档盾防住一次可识别的来枪，并说清一次失败原因；其次比较正规／老练是否让玩家觉得有机会而非被读心。

保留边界：当前枪线不预测未来步态与盾移动；人体仍是圆形区域；盾的后侧绑带／木边厚度为装饰；旋转像素仍会闪烁；没有完整新手教学、敌人职业性格库、存档云同步、近战或自由纵深。继续迭代应优先依据可复现试玩反馈，避免用更多装备或随机命中率掩盖体验问题。
