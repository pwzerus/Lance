## 玩家控制与规则

鼠标上下调枪尖；按住左键/空格催马，松手下一物理步开始惯性减速；不保留短按两秒缓存。1/2/3护头/胸/腹，右键/Q循环；W/S前倾25°/后仰45°；Esc暂停，R重开，F11全屏，H调试范围。盾按钮不催马，失焦取消按住并暂停。

巡航210、疾驰480乘马匹倍率，起跑0；催马加速度500，自动起步180，减速220，命令变化率2000。半秒巡航对照：释放前进105，催马前进143且末速约400，属于游戏单位。耐力与十匹马速度/稳定取舍沿用。

竞技场非致死、每轮新枪不回血；实战允许死亡且断枪跨轮，整体更不易断。血腥只改表现。三档AI、三轮结算、练习、商店、自动存档/三手动槽沿用；无刀剑或近战。四国72骑枪、各24甲胄/头盔/盾和10匹共通马，历史年代/身份不等同品质等级。
