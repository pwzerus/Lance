# PHYS-115 物理骑手结构（实施中）

## 数据与所有权

- `RiderBody114`：胸腔、独立骨盆/腰关节、头/四肢质点、解剖限位、有限角速率、骨长与接触。计算状态是真正的共享身体；步长固定，不保存渲染节点。
- `RiderRig115`：从现有骑手登记点抽取的纯几何。保存原始姿态、不可变骨长、头盔/靴子/盾面碰撞登记；同一当前身体生成世界坐标绘制姿态和命中锚点。
- `MountedBody115`（已接入，验收中）：每位骑手一个身体包装器，维护有限马鞍/马镫/缰绳支撑、主动肌力目标、命中冲量与失去支撑的持续时间。
- `JoustMatch` 拥有两个包装器。fighter 字典只保存值类型的当前姿态，不保存对象、回调或身体引用；避免 duplicate(true) 隐式共享身体和 RefCounted 循环引用。
- 离鞍时转移同一个 body 的所有权给 FallenRider，Model 不再重复积分。原始登记帧不重建，位置、速度和骨长不改。无界历史、重复身体和额外对冲节点禁止出现。

## 支撑与主动控制

- 马鞍是有限宽度的移动接触面，只推不拉。骨盆两处接触决定支撑与摩擦；离开边缘或抬离鞍面后没有无限固定点。
- 马镫为脚下单向支撑，有侧向可达范围；抬脚或被拉开会脱离，可在可达范围内再踩回。不得把脚永久拴在马身上。
- 缰绳为有松弛量、有限握持力的牵引。达到握持极限应松脱；两手拿枪盾不应获得额外无限支撑。
- 有意识时，姿态/手臂由有限肌力及角速率追踪玩家已经缓动的输入。昏厥后移除主动肌力，保留关节阻尼、接触与几何限位。
- 马步态只经实际移动的鞍座/马镫带动身体，不叠加独立随机人体抖动。
- 胸腔与头可接触马颈上缘；限定支撑区域，防止把已经离鞍的人再被跑来的马背顶飞。
- 盾牌增加独立转动惯量，有限握持/前臂旋转维持防护方向。盾缘接触先转盾并推动握点，再由带有限位的连接把力矩传到前臂；不把盾面方向锁死在二维投影的前臂上。
- 髋、膝独立角限位不足以限制组合姿势：新增被动跨关节张力，避免深屈髋和完全伸膝同时达到硬限位后长期悬空。系数为本游戏近似，不是人体参数标定。
- 物理始终按 120 游戏 Hz 累积，绘制插值骨方向并恢复固定骨长；慢动作缩小回调 delta 不缩小求解步，防止世界坐标 float32 舍入被速度反算放大。

## 命中与结算

- 沿实际命中点向头、胸腔、骨盆或持盾前臂施加冲量；盾缘力臂必须保留。接触可在约几个物理步内传完，不能直接改位置。
- 冲量数值到游戏物理单位的换算须通过矩阵测试校准，不称真实事故概率。装备质量影响惯性；已有头盔/入射角/冲速、伤害和竞技场计分继续独立判断。
- 落马由实际支撑丢失判断，不再由冲量阈值或低血量直接弹飞。死亡/昏厥可能先终止比赛，身体仍在马鞍上运动或随后滑落。
- 同时命中的两个候选先共同取得，再施力/伤害，不能因枚举顺序让第二个已经发生的命中消失。
- 枪尖、盾面、头胸碰撞读取身体当前锚点；渲染不得另用不一致的反冲弹簧。

## 验证边界

固定骨长/关节、左右朝向、有限控制速度、支撑释放、无输入自发落马、低速/高速及轻重甲、盾心/盾缘/头胸腹冲量、连续交接位置/速度、昏厥留鞍/滑落、两人完整对局/重开、30/60/120Hz收敛、内存和帧耗。分开记录规则、后台渲染和真人感受，不能以断言数代替画面审查。

`rig_reference115.json` 在抽取前登记 18 个左右/俯仰/举盾姿势；`rig-record24` 与 `rig-factor25` 锚点误差均 0，身体捕获最大误差约 0.000032px。它只证明重构保留原挂点，并不证明原动作本身优秀。
