# 四地区跨时代装备与解锁规划

更新日期：2026-10-23。用户已明确要覆盖多个时代与社会层次，从 1100–1300 年装备起步，通过购买、解锁和奖励扩充盔甲、纹章、武器及坐骑。此前“首发只做约 1500 年装备”的建议已被替代。此文为设计规划，不代表商店或游戏已实现。

## 已确定范围

- 四条地区线：德国、英国、意大利，以及按用户委托补选的法国。
- 早期起点：1100–1300 年；后续逐步开放更晚装备，不将整个游戏限制在单一时代。
- 社会与装备层次广覆盖：朴素、普通军用、较好订制、富裕与贵族装备、宫廷与高规格珍品均纳入长期资料和资产范围。
- 装备获取包括购买、进程解锁和奖励；贵重物品可以作为玩家奖励。
- 既有竞技场与实战规则不因本规划改变。

五个阶段的具体划分、终点、奖励频率、价格与解锁条件均是下文建议，尚未由用户确定。跨时代内容广度不等于第一版一次制作几百件；首版先完成早期可玩内容，并保留可扩展结构。

## 1. 地区线与历史身份

界面可以沿用玩家熟悉的四国称呼，但资料内部保留当时政治实体和具体地区。英国线的早期主轴建议写作“英格兰”；德意志与意大利线不假定当时已有现代统一国家。

| 地区线 | 早期研究主轴 | 后期可扩展主题 | 历史说明原则 |
| --- | --- | --- | --- |
| 德国 / 德意志地区 | 德语地区、神圣罗马帝国相关骑士装备 | 哥特式外观、特定比武甲及有据的城市/宫廷工坊 | 不将帝国边界直接等同现代德国，也不把后期专用甲放进 1100 年初始套装 |
| 英国 / 英格兰主线 | 英格兰使用的早期骑手装备与纹章材料 | 后期英格兰装备、宫廷甲与格林尼治相关主题 | 英国为界面便称；避免把现代国旗和现代统一国家身份套进早期 |
| 意大利 / 意大利诸地区 | 各地骑手装备、具体城市和领主的证据 | 北意大利工坊、米兰式装备与后期豪华甲 | 产地、订购者和使用地区分开记录 |
| 法国 | 法兰西及相关地区的比武与骑士材料 | 地区纹章、宫廷装备与具体法国工坊主题 | 法国线不是所有角色必须百合花，也不把所有法国骑士都写成王室 |

选择法国不是“最强四国”排名。Royal Armouries 的讲座介绍将早期群体马上比武的发展联系到法国北部，可为这一内容线提供历史脉络。[S38](https://tickets.royalarmouries.org/events/royalarmouries/2432732)

### 早期不强行造出四种互不相似的甲

Met 的 1000–1300 年风格研究指出，12 世纪和 13 世纪早期英、法、德、意骑手装备差异相对有限，较明显的地区差异在 13 世纪后期才更清楚。[S36](https://www.metmuseum.org/essays/fashion-in-european-armor-1000-1300)

设计建议：早期共用有据的结构基础，通过个人纹章、罩袍、盾形的具体实例、饰件、材料质量和地方身份形成差异。后期再逐步增加甲片轮廓、工坊和专用装备的区别。不要仅为四条线看起来不同就编造“德国特有 1100 年重板甲”等结构。

Met 对生产中心的研究也表明，南德意志和北意大利工坊向其他地区出口，法国和英格兰既进口也有本地生产。[S37](https://www.metmuseum.org/essays/famous-makers-and-european-centers-of-arms-and-armor-production)

因此，“法国骑士使用米兰制作的甲”可以是有据的组合；“不同年代毫无解释地拼成一套”才是需要标明的改编。禁止混搭的旧说法调整为禁止无依据的历史标签，而非禁止玩家自由穿搭或真实跨地区贸易。

## 2. 推荐跨时代进程

这些是游戏内容窗口，边界不代表欧洲各地同步换装。

| 建议阶段 | 年代窗口 | 装备研究与解锁重点 | 视觉变化目标 |
| --- | --- | --- | --- |
| I 早期骑士装备 | 1100–1300 | 锁甲、相符头盔、盾、罩袍、骑枪、基本马具和坐骑 | 从朴素但完整可读的骑手，到有个人纹章和较好装备的骑士 |
| II 板片防护发展 | 1300–1400 | 材料组合、防护部件和具体实例支持的头盔/四肢变化 | 逐步增多结构细节，不突然将全员换成晚期全板甲 |
| III 成熟板甲装备 | 1400–1470 | 合身铰接板甲、地区和工坊差异、马具升级 | 装备结构成为重要轮廓区别 |
| IV 晚期比武与骑战 | 1470–1530 | 特定哥特式及后续外观、专用比赛配置和高规格装具 | 不同用途形成明显的套装和防守轮廓 |
| V 宫廷与工坊珍品 | 1530–1600 | 具体年代支持的蚀刻、镀金、组合甲和豪华马具 | 从实用精良到昂贵装饰与收藏展示 |

上述装备方向的史实基础见考据档案 S08–S14、S32–S37；每件物品仍需单独核查。1600 是当前便于规划的参考终点，不是用户已经规定的永久内容上限。

### 玩家进程不等于一个人活过五百年

建议将跨时代进度表达成装备收藏与挑战章节，而不是默认主角从 1100 年亲身活到 1600 年。也可后续设计家族世代或历史挑战，但叙事方式尚未确定，不在本次自行定案。

已解锁的旧装备继续可用，玩家能回到较早时期搭配。是否设独立的“同代挑战”和“自由组合”规则，留待玩法设计。

## 3. 身份、经济条件与装备档次分开

“都包括”解释为覆盖不同身份和经济条件的装备与外观，不是认定历史上任何阶层都能自由参加每一场贵族比武。

| 设计层次建议 | 装备表现 | 获取方式候选 |
| --- | --- | --- |
| 基础与旧式装备 | 朴素、磨损、局部替换，结构仍应可信 | 初始装备、低价购买、基础挑战 |
| 普通军用与骑手装备 | 同期常用的实用配置 | 商店常规购买、进程解锁 |
| 精良与订制装备 | 合身、工艺更好、较完整的配置 | 较高价格、区域声望、比赛奖励 |
| 富裕骑士与贵族装备 | 定制饰件、身份图案、优质材料与马具 | 高阶比赛、章节或成就奖励、购买 |
| 宫廷与大师工坊珍品 | 昂贵装饰、著名工坊主题、有具体原型的珍品 | 特殊赛事、收藏里程碑、高额游戏内货币等 |

这不是一条真实的五级阶级制度，也不以“有钱”定义是否获得骑士身份。价格、社会身份、制作工艺、战斗用途和装饰华丽度各有字段。

例：朴素但合身的实战甲可以有良好功能；华丽的仪仗装具不必有最高防护。晚期珍品也不是所有数值都高于所有早期装备。贵重奖励可以体现在造型、历史故事、工坊来源或收藏价值，而不必全部转成伤害优势。

## 4. 装备分类

| 分类 | 建议子项 | 设计注意 |
| --- | --- | --- |
| 骑手防护 | 头盔、颈肩、躯干、手臂、手、腿足、衬层 | 按时期与原型拆分，不强制早期装备使用晚期甲片槽位逻辑 |
| 武器 | 比武枪、实战枪、相符枪头/护盘、外观变体 | 不在本次默认加入非骑枪武器的新战斗系统 |
| 盾与加强附件 | 绘饰盾、比武盾、甲上加强件 | 部分是固定附件，不全部当成手持盾 |
| 个人识别 | 纹章图案、罩袍、盔饰、徽记、旗帜主题 | 真实纹章核对使用者，虚构纹章不伪造真实出处 |
| 图章 | 如确指文书印章，可扩为印章/蜡封收藏 | 与盾徽分开；不是默认拥有一种纹章就自动取得历史贵族身份 |
| 坐骑 | 毛色、外形、训练或表现差异 | 不简单按现代品种和体型大小排列历史强弱 |
| 马匹装备 | 鞍、缰、镫、马衣、马铠 | 生物属性与护具、装饰分开 |
| 贵重装饰 | 相符时期的蚀刻、镀金、织物和饰件 | 可以作为奖励，但不凭颜色定义防护效果 |

历史广度也不意味着当前玩法之外的所有历史武器都自动加入。武器收藏的长期扩展可以另定；当前核心仍是骑枪对冲。

## 5. 推荐获取结构

用户已确定“购买、解锁、奖励”三类来源。以下具体实现为建议：

- 年代进程控制一批物品何时进入可获取范围；地区进程提供当地内容的入口，两者不要求互相锁死。
- 普通功能性装备主要提供清楚的购买路径；高价奖励物兼顾比赛、成就或收藏目标。
- 特殊纹章、外观与工坊主题可以成为奖励；不把所有华丽物品都设成纯数值碾压。
- 尽量避免四国在每个时期、每个档次机械生成完全相同数量的换皮装备；有史料与可玩差异再扩充。
- 首版暂不定具体货币、价格、掉率或任务次数；这里的购买不自动指现实付费，也不自行增加抽卡、订阅或限时商店。

### 内容广度与首版制作顺序

建议首版以阶段 I 为完整目标：四地区内容框架、共享的合理早期结构、各自经过核对的辨识元素，以及基础至贵重的代表装备。不是只做贫穷装备到后面时代才允许漂亮装饰；早期也应有同期可考的高地位版本。

建议先制作一条早期纵向流程：获得初始骑手与坐骑 → 参加比赛 → 购买第一件改善搭配的装备 → 解锁纹章/装饰 → 获得一件高规格奖励。验证循环后再扩充四条线与后续年代。

这些是开发顺序，长期范围保持四地区、跨时期、多层次。首批具体装备数量待资产预算和原型验证后制定。

## 6. 数据组织建议

每件物品分别记录下列信息，避免一个“等级”承担所有含义：

| 字段组 | 内容 |
| --- | --- |
| 年代 | 最早/最晚参考年份，游戏阶段，断代确定程度 |
| 地理 | 界面地区线、历史政体或地方、产地、使用地区、进口关系 |
| 用途 | 实战、比武、仪式或改编，模式适用性 |
| 身份 | 有据的使用者、身份语境与经济条件，不机械绑定贵族头衔 |
| 功能 | 长度、防护、质量、耐久等游戏配置与数据来源状态 |
| 工艺与外观 | 材料、制作、装饰、磨损、拆件母版 |
| 获取 | 解锁前提、购买入口、奖励来源、价格是否已定 |
| 考据 | 来源编号、馆藏号、修复情况、游戏化改动 |

在角色身份、装备产地与装备使用地区之间建立关联即可，不要求三者永远相同。玩家自由混搭是否允许及如何呈现历史标签需另定，不为“防混搭”删掉有据的贸易和订制历史。

## 7. 本次替代与仍待确定

已经替代：只做 1470–1520 年首包、先不考虑其他地区阶层的窄范围建议。

仍待确定：具体年代章节边界、进度条件、四线是否同时初始可选、首批物品名单与数量、经济数值、历史挑战与自由换装的边界、跨世代叙事，以及“图章”是否还包括文书印章。没有这些细节也能先按当前范围继续建立资料与资产原型。
