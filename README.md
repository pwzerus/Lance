# 骑枪与桂冠 · Lance & Laurel

Godot 4.5.1 + GDScript 的 Windows 单机骑枪游戏，当前开发分支为 `codex/v0.4`。当前独立分发候选为 **v0.4.42-r2**，尚未上架商店。源码、实际发布包和验收范围分别记录在 [HANDOFF.md](HANDOFF.md) 与 [最终证据](docs/development/PERF088_EVIDENCE.json)，不将自动验证等同真人手感认可。


本次重点修复首次入场与重开：完整骑手及HUD按帧准备，倒计时在就绪后开始；保留原有美术与连续动作。本机同条件首次最长帧62.2→25.5ms、后续41.3→19.1ms；仍有少量场间/终局长帧，不能承诺全程锁60FPS。
## 开始游戏

本工作区使用根目录 `Play-Latest.cmd`。新版独立包完整解压后，双击最外层 `LanceAndLaurel.exe`；保留旁边的 `runtime` 和 `licenses` 文件夹。外层程序同时启用内存保护，不需要安装 Godot、Codex 或 PowerShell。不要单独搬走 EXE，也不要绕过外层启动 `runtime` 中的游戏。

本地压缩包为 `builds/LanceAndLaurel-v0.4.42-r2-Windows.zip`，约64 MiB；完整解压约125 MiB。GitHub分支保存源码和验收文档，未自动上传二进制Release。上一可运行版本及中间候选保留，只有本根入口指向本次最终候选。

第一次进入建议选择「练习场 → 分步练习」。七项练习依次教会催马、收速、稳定枪线、举盾、前倾回正、观察实际接触和挡住来枪。教练先收枪，再在防守步骤出枪；完成后可直接看小结。自由练习也保留，练习不计战绩、不发奖励。

## 操作

| 操作 | 当前行为 |
| --- | --- |
| 上下移动鼠标 | 调整枪尖高度；停手后稳定，大幅改向会耗费臂力并暂时失稳 |
| 按住左键或空格 | 持续催马；松手后逐步回到巡航。点一下只是一小段催马，没有旧版的两秒自动冲刺 |
| 1 / 2 / 3 | 护头 / 护胸 / 护腹；盾牌有真实移动过程 |
| 右键或 Q | 在三个盾位之间循环 |
| W / S 或上下方向键 | 前倾支撑 / 后仰避头，带连续姿态过渡 |
| 纯鼠标设置 | 滚轮调前后倾身，中键回正；其他鼠标操作不变 |
| Esc | 暂停、继续、重开或回营地；比赛中的血腥和震动选项也在这里 |
| R | 重新比赛；分步练习保留本次已完成的步骤 |
| F11 | 切换全屏 |
| H | 显示或隐藏实际判定范围，默认关闭 |

马匹会基础前进。连续催马更耗马力，迟发冲刺又需要起速距离；高速与收速之间要留出调枪、举盾的时间。马力与骑手臂力不同，乱甩枪不会给马补充体力。枪盾不能瞬移，没有自动吸附目标。

战斗提示区分盾心、盾面、盾缘与身体接触；颜色和文字一起反馈。结算可展开细节。设置可分别控制总音量、营地音乐、动作音效和风声，并试听钢盔、板甲、木芯盾的接触；也可关闭震动、慢动作或部位提示。静音不改变规则。

## 两种模式

**竞技场**非致死，最多三次对冲，每轮换新枪但不回血。落马或无法继续时提前结束。干净盾牌接触1分，达到实击门槛的胸腹2分、头盔3分，本次有效接触断枪再加1分；较弱轻触1分，擦偏不计分。三轮后先比较分数，同分再比较骑手状态；仍相同则平局。腿部装饰不增加护甲，也不是独立得分区。

**实战**允许死亡，没有竞技场计分胜负。有效重击可一击终结，头盔、盾牌和擦偏仍可保命；多次有效头伤会累积，不能将每次碰到头都视为必死。断枪后保留残柄；终局立即停止继续攻击。三轮无落马时比较骑手剩余状态。死亡只结束本局，不删除装备收藏。没有拔刀近战。

现实比武没有统一的全欧洲计分体系；固定跑道、三轮、伤势及断裂参数是本作改编，不是历史医学或材料试验结果。游戏内历史手记和军械库标明器物来源与推断边界。

## 收藏与成长

英格兰、法兰西、德意志、意大利四条收藏路线，从1100–1300主题窗口逐步解锁到1530–1600。每国包含六件考据头盔、六件考据胸甲，以及三类各六档的骑枪；兼容的旧藏保留。坐骑共十项，速度、稳定性、耐力有取舍，使用四套毛色，四国共用。马衣、盾面纹章与人物外观可以搭配。

当前数据合并后为186条装备记录，包含兼容旧藏和“无马衣”；这不代表186个完全独立的美术模型。历史出处、收藏地区、制造地点与游戏解锁年代分开说明。贵重装备有重量代价，不是所有属性都优于轻装。

可用银币购买，随声望解锁年代；没有现实付费抽取。竞技场胜/平/败基础奖励分别为180/110/55银币和3/1/1声望；实战另加30银币。穿纹章马衣获胜可增加声望奖励。没有永久死亡或失败清空收藏。

## 保存与恢复

自动档、自动备份和三个手动槽均在 Windows 用户文件夹，不写在安装目录。默认目录：

`%APPDATA%\Godot\app_userdata\骑枪与桂冠 · Lance & Laurel\`

主档 `profile_v1.json`，备份 `profile_v1.backup.json`；手动槽 `profile_v1_slot_1.json` 至 `profile_v1_slot_3.json`，各有 `.backup`。关闭游戏后备份整个存档目录即可。覆盖和读取手动槽需要确认。

主档损坏先尝试备份；两份都不可读时会进入恢复页，不静默覆盖。选择有效手动档或开始新旅程前，会保留损坏文件副本。写入失败会保留未保存提示，结算可重试，不重复发奖。测试使用独立 `qa_` 路径，不能用正式档做故障注入。

## 运行保护与适用范围

目标为 Windows 10/11 x64。当前实测机器为16 GB内存、Intel集显、OpenGL Compatibility；没有据单机测试宣称所有硬件稳定60 FPS。窗口最小960×540，推荐至少1280×720。

游戏启用1 GiB进程组上限、900 MiB私有内存提前停止、至少500 MiB系统余量和单实例；启动还需约1.74 GiB可用内存预算。预算不足会解释原因，不会替你关闭其他软件。限制用于避免资源失控，不代表全部电脑内存占用或显存都能由游戏控制。最小化会停止重建画面，进行中的比赛暂停，恢复后需主动继续。

独立启动器日志位于 `%LOCALAPPDATA%\GALUMU\LanceAndLaurel\logs\`。出现异常时，请保留最新日志、版本号和发生步骤。程序未数字签名；尚未完成跨机器兼容性与玩家自然度/听感验收。最终候选的具体证据见 [COMM-087审查](docs/development/COMM087_REVIEW.md)。

## 开发接手

先读 [HANDOFF.md](HANDOFF.md)、[AGENTS.md](AGENTS.md) 和最新协作记录，核对实际HEAD及未提交差异。保留对方成果，不用旧快照覆盖。GitHub为 [pwzerus/Lance](https://github.com/pwzerus/Lance)；同版本在 `codex/v0.4` 分项提交和推送，不 force push。

测试、导入和导出均经 `Start-MemoryBound.ps1`，使用 `-- --test-profile`；需要画面时加 `-IsolatedDesktop`。默认不接管用户屏幕。不要同时启动多个游戏或绕过保护。使用Godot4.5.1，导出模板路径在 `game/export_presets.cfg`；新包放独立builds子目录，不覆盖旧包。新版外层启动器由 `launcher/Build-Launcher.ps1` 编译，与开发保护器复用同一核心。

规则模型在 `game/scripts/core/joust_match.gd`；输入/比赛演出在 `battle.gd`；菜单与存档在 `main.gd`、`core/game_state.gd`；装备数据在 `game/data/`。美术来源、历史研究和玩家反馈研究分别见 `game/art_sources/`、`docs/HISTORICAL_RESEARCH.md`、`docs/PLAYER_FEEDBACK_RESEARCH.md`。`builds/`不进Git，推送代码不等于上传可执行包。
