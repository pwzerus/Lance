# ART-063 马匹外观（Claude 重绘）

四套运行时马皮：bay（枣红）、flaxen（栗色浅鬃）、grey（连钱灰）、black（黑）。四国共用，十匹马的外观映射与属性不变（catalogue.gd 的 HORSE_COATS）。

## 怎么来的

由 `game/tools/horse_coat_v063.gd` 在 Godot 中逐像素生成，参数和规则都在脚本里，可完全复现。没有调用任何图像生成模型。

- 唯一母版：`assets/art/pixel_v050/horse_complete_skin_v050_01.png`。蒙皮骨骼挂点都是在这张图上测的，所以四套外观共用同一个轮廓和对位，没有 ART-060 那种各图轮廓约 98% IoU 的偏差。
- 原样保留母版的外轮廓黑线、马鞍、鞍垫、肚带、笼头、蹄、眼和白色标记。鬃毛和尾巴保留发丝结构，按毛色重新上色。
- 马皮整块重画，不沿用母版的明暗。原图的肌肉被画成一层层人字形条纹（栗色马还叠了细密噪点），缩小显示后就成了用户说的“密集裂纹”。新画法：
  - 用两种尺度的剪影推算躯干和四肢的圆柱体积；
  - 叠加 21 块按马的解剖结构布置的肌肉隆起（臀、股二头肌、膝、飞节、肩胛、三头肌、颈部、脸颊等，都是高斯形起伏）和 3 条又宽又浅的凹沟；
  - 由此算出法线，用偏上方的光源打光，再加凹处遮蔽和柔和高光；
  - 配上各毛色的色带：枣红偏红棕，栗色偏铜红，灰马带柔和的连钱斑、头部和下肢偏深，黑马带蓝调光泽。
- 关节缝：母版在肘部和膝前（腹部轮廓与腿相接处）的外轮廓黑线会随腿部权重被拉进身体，形成黑线。这两处的黑线和其抗锯齿边缘改画为马皮色。
- 运行时尺寸 1024×683。UV 仍按 1536×1024 源坐标计算。

## 运行方式

采用 Godot 标准纹理导入：无损压缩，开启 mipmap，不限尺寸。`horse_skin.gd` 把它包成 CanvasTexture，只对马皮使用线性加 mipmap 过滤，骑手和装备仍沿用画布的最近邻过滤。原来马皮采用最近邻采样且没有 mipmap，而游戏里马只按原图 0.18–0.45 倍显示，每个屏幕像素要跳过 2–5 个纹素，细笔触因此混叠成闪烁的裂纹。剪影仍由 `mounted_pixel` 着色器在 alpha 0.5 处裁切。

旧的 v050 母版和 `horse_coats060` 已不再被游戏代码引用（只有生成工具读取母版），已在 `export_presets.cfg` 中从导出里排除，源文件仍保留在仓库里。

## 边界

这是程序化的“绘制”，不是逐像素手绘，也不是任何具体历史马种的复原。肌肉位置凭解剖常识在侧视图上估计，不是测量值。最终是否好看，仍需玩家在游戏里实际观看确认。
