# de_armor_1 built-in imagegen prompt

Use case: historical-scene. ONE modular TORSO armor sprite for GALUMU. Reference is pixel style and3/4 right orientation/framing only; DO NOT copy its decoration or construction. Torso chest partly facing viewer, face direction RIGHT, neck opening through waist/upperhips, no head/skin/human/arms/sleeves/hands/legs/mannequin; shoulder sockets clear for independent animated arms. Genuine transparent background with no ground shadow,text,labels. Clean large pixel clusters, dark strong outline, broad structural highlights, no noisy microtexture or fine photoreal scratches. Isolated single complete torso centered square. Subject early14th-century German-speaking tournament rider MAIL UNDER HERALDIC SURCOAT, inspired by actually inspected Codex Manesse cpg848 fol17r(c1300–1340,Zurich). Cloth surcoat dominates: sleeveless softly draping tunic over mail, simple dark blue/red quartered or vertically parted original color panels, restrained cream edging and one original plain geometric diamond emblem rather than real family coatofarms. Mail rings only at round neck/armhole edges and short lower hem. Cloth hanging riding split at lower front, plain brown waist belt. Absolutely NO solid plate breast/shoulder armor, no raised steel gorget, no rows of rivets, no later tassets, no elaborate gold filigree. Strong cloth folds and irregular drape differentiate it from rigid metal cuirass.

Historical photo actually inspected separately; imagegen could not decode the museum reference file through this environment, so only the existing project style image was supplied. This is an original game adaptation, not a pixel tracing of the historical object.
