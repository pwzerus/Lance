# FEEL-072：后台画面复核与可辨认的命中受力

日期：2026-11-09；Codex。接手分支 `codex/v0.4`，实际本地/远程基线 `03d450afae5e521aa3eb84e66cfc8520eeb31d29`，源码及入口 v0.4.28。Claude 的 HORSE-065、EQUIP-066–069 已提交接收，保留其重量、疲劳、臂力、有限枪盾操控、计分实击门槛。接手时 `game/tests/rules_v045_results.json` 及历史未跟踪材料未归入本轮，不覆盖或暂存。

用户要求后台检查人物/马匹动作、头盔衔接、马衣纹章和疲劳显示；改善盾心、盾缘及人体命中的辨识与撞击震感。不得接管屏幕，系统保留线1GiB，其余保护开启。

## 诊断与修改

| 发现 | 原因 | 本轮修改与范围 |
| --- | --- | --- |
| 盾牌命中只报告“盾牌格挡”，边缘与中心难区分 | 连续扫掠只返回接触点；反应只有前后压缩，没有偏心扭转 | 保留真实扫掠与命中先后，记录局部接触点和来向，按力线偏心率区分盾心/盾面/盾缘。HUD、结算、短时落点标记使用同一事件 |
| 受击像轻点一下，盾缘缺乏方向反应 | 既有全身反冲较小，盾牌始终平移 | 盾心主要压向持盾手，盾缘按有符号力臂绕握柄扭转；同一有限弹簧连续恢复。头/胸/腰腹分别带动已有躯干反应；加大有上限的镜头冲击、降低反弹频率 |
| 马尾与后蹄白袜在重叠时呈梳齿条纹 | 尾巴/后腿的权重过渡跨过透明缝；网格按行绘制使两者的三角形交替覆盖 | 沿源图透明缝拆开网格连接，先画完整马尾，再画近腿。主网格固定2214顶点，比原2173多41，不添加纹理或逐帧拓扑 |
| 疲劳已为0仍显示每秒消耗，满值恢复时亦会误报 | HUD显示理论变化率，未考虑数值夹限 | 0时负变化、100时正变化及结束阶段显示0；不修改疲劳规则 |
| 少数短测正常结束，保护器却抛进程已退出异常 | 1秒等待后、读取进程内存前存在退出竞争 | 缓存同次采样；只在原进程句柄确认退出时接受该异常。其他异常仍抛出，所有保护阈值不变 |
| 旧画面测试误报枪盾瞬移 | v058测试上限遗漏EQUIP-066轻甲灵活度乘数 | 新072测试使用实际规则乘数；没有放宽生产规则或跳过连续位移检查 |
| 结算出现“盾心正挡”同时“擦偏” | 部位分类与正挡/擦偏规则不是同一维度 | 最终用“盾心受击”；独立显示擦偏，不暗示一定正挡 |
| 完整对局结算的长说明压住奖励 | 原固定位置假设说明最多119px，护甲/断枪文本换行后超出 | 说明使用110px独立滚动区域，奖励与按钮不再被覆盖；960×540长说明及实际整局结果均复核 |

盾牌分类是侧视游戏的**投影近似**：扫掠首次进入必在轮廓边界，直接用该点到中心的半径会把所有命中误判为盾缘。因此计算入射力线相对盾面中心的垂向偏心率，低于0.38为盾心，高于0.72为盾缘，其余盾面。这不是实测三维接触面或SI单位刚体仿真。原伤害、擦偏、破盾、得分和实击门槛17不变；受力后的连续姿态可能影响之后的接触，与既有反应系统一致。

受击标记为已确认事件，保留0.62游戏秒，随实际受击表面移动；不是额外瞄准提示。盾心金色、盾缘橙色、头部红色、胸部青色，文字辅助辨别，不能只凭颜色理解。枪盾主动移动仍有时间过程，受击只注入速度，不直接改位置。镜头横向冲量上限22→29逻辑像素，衰减窗仍0.48秒，震动关闭时完全归零；既有近身/命中缩放和慢动作时序沿用。

## 保留的失败与边界

- 开始时RAM不足被启动预算拒绝，未关闭保护；之后余量恢复才运行。
- 一次把四国图集放同一512MiB诊断进程，采样470.8MiB触发448MiB早停；拆为四进程后峰值378.2–398.8MiB。完整HUD误用512档时493.1MiB早停，改用既有完整游戏1GiB档，未提高任何限额。见 `feel072-fit02-memory.txt`、`feel072-hud01-memory.txt`。
- `feel072-legs01`漏传必需输出路径，退出2；补路径后的legs02通过。
- `feel072-feedback01`因旧测试忽略轻甲乘数失败；feedback02按既有真实规则修正后通过。失败JSON及日志保留。
- `feel072-result01`新测试对有类型数组赋空无类型数组，脚本停在夹具构造；保护器超时终止。改为clear()后result02及实际最终包result01均通过。该失败发生在测试脚本，不是玩家结果页逻辑。
- 部分环境日志报不能建立 `user://` shader cache；导出结束报编辑器设置路径为空。导出退出0，PCK已实际运行；未把这些信息隐藏成“零错误”。不改系统目录权限。
- 旧 `test_hud067`启用Main完整smoke流程，测试自己启动的对冲又被菜单巡游替换，结束时仍有待执行计时器；其初包对局记录退出时ObjectDB提示不能作为干净退出证据。新 `test_match072`仅同步开启Battle自动操控、随后关闭Main巡游，测试清理完整场景与音频后退出。初次记录保留供比较。
- 初包正式竞技场式QA在受限环境无法写 `user://qa_profile_v1.json`，结算正确显示未保存；本轮不宣称存档写入验收。最终整局用练习模式避免奖励/写盘，仍走实际AI/三轮/结算。
- 没有OS输入、真人试玩或扬声器听感验收。音频驱动Dummy；本轮沿用材质声音，没有假称重新录制或听到更好。
- 罩袍纹章仍未实现；本轮确认的是已有马衣纹章。头盔检查不是全部跨国/跨档组合，无法保证所有极值像素都完美。重甲镜像平衡/实击17/臂力与疲劳的真人调参仍待进行。
- 1秒采样峰值不是瞬时峰值；有限后台验证不能证明历史40GB全部故障已根治，继续保留全部资源保护。
