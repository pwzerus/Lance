# 资料与边界（2026-10-24）

- [Godot 4.5 Camera2D](https://docs.godotengine.org/en/4.5/classes/class_camera2d.html)：官方 API；本项目用 zoom、offset、force_update_scroll 管理画面，世界受击锚点不随震动移动。
- [Godot 4.5 InputEvent](https://docs.godotengine.org/en/4.5/tutorials/inputs/inputevent.html)：官方输入传播文档。Control 事件消费与全局 Input 按键状态应分别分析，不能把左键体验差一概归咎于 UI。
- [game-feel Skill 作者仓库](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/main/skills/disciplines/game-feel/SKILL.md)：参考其对动作反馈、顿帧与镜头的分类；这是社区工作流，不是 Godot 官方标准，也未安装或执行仓库代码。当前项目 Skill 根据实际骑枪问题重新撰写。
