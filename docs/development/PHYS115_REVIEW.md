## 已定位问题（开发中，未宣称发布通过）

1. 悬空屈膝：PHYS-114 的 KNEEL_GIVE 为髋后伸多开放 1.2 弧度，四个遗留夹具最终约 -95°。删除此补偿；正常关节限位保留。
2. 盾臂突转：不仅绘图问题。原始前臂也在地面碰撞后的约束投影中突然旋转。链旋转加全身反旋的启发式改为关节角 Jacobian；盾缘离开前臂轴的力臂纳入接触计算；物理关节增加有限角速率阻力。
3. `phys115-shield105-rates04`：18/18 原盾臂夹具通过，最大单步转角 0.101714 rad；修复前最大 0.41985 rad。另有世界空间诊断上限约 0.110 rad。只证明该组有限角度与握点连续，不能证明完整游戏动作合格。
4. `phys115-body-rates04`：悬空腿原失败消失，但仍有三例慢收势，两个昏厥滑落躯干离地约 31px。隔离 GPU `phys115-fallview05` 确认：先倒下再被撑起。需要修复，不降低验收门槛。
5. 试验 `phys115-contactonly06` 去掉几项准静态补偿仍未解决；`phys115-lowgrip07` 减少摩擦改善收势，但支撑姿势仍失败。根因之一是胸腔与骨盆刚性合并，腿部限位可将整块胸腔撑住。下一步增加有限腰部连接，不再通过异常髋后伸消除支撑。
