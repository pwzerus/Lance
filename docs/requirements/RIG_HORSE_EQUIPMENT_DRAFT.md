# 人物连接、马匹运动、赛道分层与装备扩充需求

状态：2026-10-27按用户最新澄清修订，供核对阶段范围。已确认起伏适度影响枪线、节奏可预判、玩家能控制、不随机偏枪；完全删除刀／剑及拔刀近战。当前仅整理文档，未开始实现。可玩基线为v0.4.1，文档基线57d205f，分支codex/v0.4。

## 1. 本轮优先顺序

先解决人物肢体连接、穿插、马匹步态与接地、栅栏两侧的空间关系，达到可接受的实际试玩效果，再扩充装备。人物／马匹基础表现未修好时，不以新增大量装备作为完成当前要求的替代。

用户反馈是当前版本存在的问题；此前的自动测试和截图通过，不能抵消玩家指出的穿模、断开与漂浮。本轮整理未重新试玩，不把玩家报告写成开发者已经复现。

## 2. 人物连接与美术表现（第一优先级）

| 用户指出的问题 | 需要达到的结果 |
| --- | --- |
| 手臂穿过身体、装备或另一条手臂 | 理顺远近手臂、身体、盾和枪的遮挡关系；避免无依据的穿入、穿出和错层 |
| 肢体连接不上、像漂浮零件 | 肩—上臂—肘—前臂—手连续连接；腰／髋—腿—脚也检查，不仅修一个画面里的手 |
| 姿态变化后连接失效 | 左右朝向、前倾、后仰、抬枪、压枪、高低盾、受击和落马都检查；动作过程不能只在静止时拼得上 |
| 装备替换可能再次错位 | 新旧盔甲、盾与武器使用明确挂点；装备扩充后继续逐套验收 |

保留已确定的非写实像素风和有装饰的骑士装备，骑手仍以三分之四朝镜头展示。此处“建模”首先指当前2D分件、比例、关节和遮挡关系的修正；没有因此新增改用完整3D的决定。

## 3. 马匹运动与地面关系（第一优先级）

- 马匹必须有明显的纵向起伏、承重压缩、蹬地、收腿和腾空。马身、颈头、四肢、马尾与骑手相互配合，避免整张形象平移、只有腿摆动的效果。
- 加速／高速运动应增加步频、步幅和有力量感的身体起伏；骑手随鞍座运动，身体与持枪手保留合理的缓冲和滞后。
- 起伏以有节奏的步态为基础，可以有轻微、连续、有界的不均匀感；不把不稳定做成每帧随机跳动。具体幅度和曲线是后续调校参数，不在草案里伪称历史实测值。
- 支撑阶段马蹄贴合各自跑道的实际地面，不悬空、不穿地、不明显滑步；腾空阶段可以离地，落地后必须重新承重。身体上下起伏时，支撑蹄不能跟着整匹马一起被抬离地面。
- 阴影、扬尘、蹄声与实际接地／腾空阶段相符；镜头震动另行控制，马匹起伏由马体和骑手动作直接体现。
- 高速马必须保留明显运动起伏。高品质／高稳定性可以改善控制和不规则晃动，不能把快速奔跑变成无颠簸的匀速滑行。

用户已确认：**马匹起伏适度影响实际枪尖轨迹、瞄准和命中；节奏可预判、玩家能控制，不做随机偏枪。** 起伏通过马匹—鞍座—骑手—持枪手传递；玩家可根据步态节奏修正瞄准，维持枪线。实际显示的枪尖与碰撞判定必须一致，不能只移动贴图而命中仍停在旧位置。具体幅度和可控范围由后续试玩调校，不以随机命中概率代替动作影响。

## 4. 栅栏两侧与画面分层（第一优先级）

两名骑手应分别位于隔栏两侧的跑道。横版画面要让玩家看清近侧和远侧，不是仅把两骑放在屏幕左端和右端，却都画在栏杆前面。

验收方向：远侧骑手／马匹 → 中间隔栏 → 近侧骑手／马匹形成清楚的遮挡关系，各自有正确地面落点、阴影和纵深偏移。栏杆应真实隔开赛道；骑枪交锋的位置、人物身体与实际命中位置保持一致。具体投影和绘制顺序由实现诊断确定，不把所有对象固定套用一个层级数字。

本项针对有隔栏的场景；没有新增对实战模式作完整战场重构的要求。

## 5. 四国装备扩充（第二优先级）

地区沿用：德意志、英格兰、意大利、法国。装备沿用历史考据原则；国家线是游戏组织方式，不强行给跨地区共用形制编造独有起源。

品质分为六档，按用户原意整理为：

1. 新手装备
2. 初级装备
3. 中级装备
4. 中高级装备
5. 高级装备
6. 最高级装备（最终显示名称可再调整）

品质等级与历史年代分别管理。保留从1100–1300起步、随后解锁更多时代的既有方向，不把六档品质直接当作六个年代，也不把后期盔甲塞进早期历史主题。

### 已确认的骑枪数量

用户在本轮澄清：**每国3类骑枪，每类6档品质**。

| 地区 | 类型数 | 每类品质档数 | 装备条目数 |
| --- | ---: | ---: | ---: |
| 德意志 | 3 | 6 | 18 |
| 英格兰 | 3 | 6 | 18 |
| 意大利 | 3 | 6 | 18 |
| 法国 | 3 | 6 | 18 |
| 合计 | 12条类型线 | 各6档 | 72 |

72是装备条目数，不等于已经决定制作72套完全独立动画或宣称存在72种历史专有形制。三类骑枪的具体名称、用途、差异、史料和各档造型需在实现前做设计；竞技场与实战的枪头／断裂差异沿用既有模式原则，不能未经确认再把总数翻倍。

### 其他装备覆盖

- 各国均有甲胄／头盔、盾牌，并覆盖六档成长。
- 马匹另设共通目录，不按四国复制。
- 外观、价格、解锁和实际属性应支持成长与选择；具体各类数量、是否进一步拆成手套／护腿等槽位尚未确定。
- 骑枪的“三类×六档”数量规则只明确适用于骑枪，不能直接推断每国每个装备类别都必须18件。
- 用户明确纠正：**装备中没有刀、剑，也没有拔刀近战。** 删除相关商品、装备槽位、美术制作、拔刀动作和战斗流程的规划；不将刀剑作为装饰性副武器保留。
- 新装备需要能在购买、解锁、装备、人物展示和存档中正常工作；旧玩家收藏及存档兼容方案需在实施时确定。

## 6. 共通马匹：总共10种配置

确定要求：全地区共用10种可购买／解锁的马匹配置，从新手覆盖到高阶；主要选择维度为速度和稳定性。是否按真实历史品种命名、具体外形、价格、解锁位置与参数尚待设计，不以虚构品种充当考据结果。

必须存在取舍：

| 方向 | 玩家得到什么 | 必须保留的代价 |
| --- | --- | --- |
| 偏稳定 | 节奏较规律，较容易维持骑姿和枪线 | 速度或冲锋能力较低 |
| 偏速度 | 更快接近和更强的冲锋感 | 颠簸／控制负担较明显 |
| 折中 | 速度和稳定性都可用 | 两者都不能达到各自最优 |
| 高阶偏速度 | 较快，并比低品质快马更可控 | 仍明显颠簸，不能同时达到最稳 |
| 高阶偏稳定 | 比入门稳马更有性能，且相对好控制 | 仍需让出最高速度 |

以上是配置方向，不是已经拟定了5种而减少到5匹；最终条目必须为10种。不能出现最快、最稳、几乎不抖且没有其他取舍的全能马，也不能仅凭最高价就取消全部操控代价。

具体等级分配和数值表需后续制定。稳定性与正常奔跑起伏要分开表达：稳定性较好的马仍然会上下运动；改善的是运动规律性／可控性，不是取消步态。

## 7. 分阶段完成标准

阶段A：先复现并记录人物穿插／断开、马蹄离地、平移感和同侧赛道问题；修复一套完整骑手与马匹，在实际游戏速度下检查左右双向、极限姿态、加减速、命中、断枪和落马，并接入可预判、可控的起伏对枪线的适度影响。需要有实际窗口试玩和连续动作证据，不能只凭单帧截图或规则断言结束验收。

阶段B：基础连接与分层通过后，制定四国三类骑枪／六品质档，以及其他装备和10种共通马匹的数据与美术清单；逐批接入购买、解锁、存档和可见装备，并复验挂点。

阶段C：检查高速／稳重／折中马是否真的形成选择，是否有明显无代价的最优项；检查起伏与瞄准可读性、伤害与模式规则是否保持一致，再交付新的独立版本。

本轮没有给出新的开发时长、没有开始上述阶段。整体需求经用户核对后再实施；是否需要下一版本分支按实际结构改动判断，不预先宣称已创建。
