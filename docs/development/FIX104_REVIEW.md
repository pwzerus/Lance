# FIX-104：第二关持枪臂与落马特写

基线 `ea6506fcc45698302bcd74356f753356babb00dc`，运行源码 `cb5a1169772e6dc11802ef1ce5f31d0cabcb817b`，v0.4.56-c1 / codex/v0.4。接手核对本地与 origin 一致，保留三份历史差异和旧 QA/UID，未恢复旧快照。

## 已定位并修复

1. **P1 人物淡化变成整块消失。** `battle._update_views` 为让远侧落马者可见，把前景 RiderView（马和骑手一起）透明度降至0.20；`mounted_pixel.gdshader` 又以最终 `COLOR.a<0.5` 丢弃像素。真实 GPU 夹具在 alpha=1/0.55 可见采样35931/35459，0.45/0.20却变为0。现在按源贴图 alpha 裁切提取白边，保留最终透明度；遮挡只调 `horse_opacity`，人物保持不透明。没有藏掉骑手、移动命中点或修改落马轨迹来掩盖问题。
2. **P2 左向持枪臂垂到腹前。** 手掌原本与真实枪柄相连，问题在于近乎正面的肩口与侧向握点距离很短，却仍用44/46像素的完整骨长解二维肘部，导致深折肘落到腰带附近。现在仅远侧持枪臂使用0.64–1.0的连续深度投影，握点、枪尖、盾柄、肩口和胸甲保持原坐标；近侧臂与盾臂保持旧实现。落马抓取投影后的当前骨长，不在第一帧拉长或消失。
3. **P2 战败特写过长。** KO停顿0.23秒保持；阅读段2→1.05秒、释放0.60→0.38秒。终局等待下限2.6→1.8秒、上限6.5→3.6秒；继续跑原落马和马匹离场运动，结果遮罩出现后不重新站起。暂停不消耗预算，关闭慢动作/退出/重开恢复时间。新等待上限不代表物理落稳保证，完整物理落稳另用72姿态回归验证。
